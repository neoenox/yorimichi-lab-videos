# 制作サイクル（日刊）

公開：毎日 19:00 に長尺、20:00 に Short（Short は長尺と同じ題材で、本編へ誘導）。

## 1. 流れ（1本あたり）

| 段階 | 内容 | 使うもの | 目安 |
|---|---|---|---|
| ① 題材策定 | 候補出し（Claude と web版ChatGPT が別々に）→ 相互採点 → `topic_pick.py` で傾向を反映 → 上位に一次資料の関門 → 人が決定 | web版ChatGPT（ブラウザ操作）、`topic_pick.py` | 週1回、まとめて7本分 |
| ② 事実確認・台本 | `08_fact_check.md` → 台本v1 → web版ChatGPTで台本査読 → 台本v2（指摘は裏取りしてから反映） | Claude、web版ChatGPT | 1本 約2時間 |
| ③ 画像 | 章ごとのイラストを web版ChatGPT で生成（1章に1〜2枚）。データ由来の図は自作 | web版ChatGPT | 1本 約20分 |
| ④ 制作 | `vp.py`（story→kana→audio→ends→build→desc→pack）、Short は `make_short2.py` | VOICEVOX、ffmpeg | 1本 約10分（待ち） |
| ⑤ 評価 | Codex の通し視聴と読み確認。指摘は一次資料・実フレームで裏取りしてから反映 | **Codexはここだけ** | 1本 約5分（待ち） |
| ⑥ 投稿 | 非公開でアップ → 予約（毎日19:00）。`finish_all.py` | Studio（ブラウザ）、YouTube API | 1本 約10分 |
| ⑦ 反応の計測 | 公開後 48時間と7日で、Studio の数字を記録 | Studio（ブラウザ） | 毎日 数分 |
| ⑧ 傾向の更新 | 毎週月曜に集計 → `channel_profile.json` → 再採点 → ①へ | `topic_pick.py` | 週1回 30分 |

## 2. 在庫の規則

- 予約済みの在庫を、常に **7日分以上** 保つ。5日分を切ったら、制作を優先する。
- 制作は、公開の **約2週間先** の分を作る（反応の計測が1週間かかるので、反応を反映できるのは、そのさらに先の動画）。

## 3. 反応の見方（Studio）

| 指標 | 見る時点 | 使い方 |
|---|---|---|
| インプレッション数・クリック率 | 48時間 | 題名・サムネの当たり外れ |
| 平均視聴時間・視聴維持率 | 7日 | 構成・長さ・画面の良し悪し |
| 再生数・登録者増 | 7日 | 題材の人気 |
| Short の「視聴継続率」 | 48時間 | Short の出だしの強さ |
| 流入元（検索・関連・ブラウジング・Short） | 7日 | 題材が検索型か発見型か |

`data/channel_profile.json` の各動画に、`views`・`ctr`・`avg_view_pct`・`subs` を追記する。

## 4. 傾向の使い方（探索と活用）

- 題材の約7割は、伸びた分野・型に寄せる（活用）。約3割は、新しい分野・型を試す（探索）。
- 15本公開するまで（約2週間）は、実績の重みを小さくし、分野を偏らせない。
- 1か月ごとに、本数・長さ・Short の有無を見直す。

## 5. 週の暦

| 曜日 | やること |
|---|---|
| 月 | 前週の計測の集計、傾向の更新、題材策定（7本分） |
| 火〜金 | 事実確認・台本・制作・評価・アップ（1日に1.5本ペース） |
| 土日 | 在庫の点検、予約の確認、翌週の準備 |
| 毎日 | 前日・前々日の動画の数字を記録 |

## 6. 品質の関門（省略しない）

一次資料の確認 → 台本査読 → Codex の通し視聴 → 読み確認 → 予約の確認。時間が足りないときは、本数を減らし、関門は省かない。

## 方針変更(2026-10-20): 量産感の解消
- 見た目が似すぎ・型が固定、という指摘を受けた。収益化審査(真正性に欠けるコンテンツ)の観点でも、型の固定は不利。
- 公開ペースは、予約済み分を出し終えたあとは週3本程度を目安にする(日刊を絶対条件にしない)。
- サムネイル: 分野ごとに配色(shade_col/accent/bar_col)を変え、結論の一言を大きく。`vp.py thumb`のspec `thumb`で指定。
- 構成の型を使い分ける: A 答え先出し(俗説の検証) / B 逆転(常識→実は) / C 仕組み(段階的な図解)。「決められないこと」は最後の一言にとどめ、章にしない。
- 画風は分野ごとに変える(水彩・切り絵・図鑑の挿絵など)。ChatGPTへ渡す固定文面を分野別に用意する。
- 型ごとの反応を channel_profile.json に記録して比べる。

## 反応の記録（2026-10-20 追加）
- 集計：`python scripts/collect_stats.py`（YouTube Data API。視聴・高評価・コメント。約1〜2ユニット）→ `data/channel_stats.jsonl` に追記。
- 傾向：`python scripts/collect_stats.py --report` が、種別（長尺/Short）・構成（旧/B/C）・分野・サムネ（旧/新）ごとの「1日あたり視聴」を出す。メタ情報は `data/video_meta.json`（新作は追記する）。
- 維持率・平均視聴時間：Data APIでは取れない。Studioのアナリティクスを開いて読み、`data/studio_notes.md` に、公開48時間後・7日後の数字を追記する。
- 判断：本数が少ないうちは、差が出ても傾向とは言わない（目安）。型・サムネの比較は、各条件3本以上たまってから。
- 公開済みの最初の動画：排水(10/18)、静脈(10/20 19:00)。
