# 次の動画の題材を決めるロジック

チャンネルの傾向（形式・カテゴリ・実績）から、候補に点をつけて順位を出す。`python scripts/topic_pick.py --month 11 --top 10`

## チャンネルの型（これに合う題材を選ぶ）

「よくある思い込み」→「公的な一次資料で確かめる」→「数字と図で見せる」。約4〜7分。画像は自作の図か生成イラストで、権利の問題が出ない題材。

## 入力

| ファイル | 中身 | 更新のしかた |
|---|---|---|
| `data/channel_profile.json` | 既存動画（カテゴリ・タグ・公開日・再生数） | 公開後、Studio のアナリティクスの再生数を `views` に追記 |
| `data/topic_candidates.json` | 候補（問い・資料・見せ方・権利の各0〜5点、季節、既存との接続、関門） | 候補を足す／採用したら `channel_profile.json` に移す |

## 総合点（100点満点）

| 項目 | 重み | 見方 |
|---|---|---|
| 基礎点 | 45% | 問い35・資料30・見せ方25・権利10 の加重平均 |
| 新しさ | 15% | 既存動画とのタグ・題名の重なりが小さいほど高い |
| カテゴリの偏りの是正 | 10% | 既存でその分野が多いほど低い（今は地球・暦が多い） |
| 既存動画との接続 | 10% | 続けて見てもらえる動画が2本以上あれば満点 |
| 実績の傾向 | 10% | 再生数が出た分野・タグを加点。3本未満の実績では中立 |
| 季節 | 10% | 今月〜2か月先の公開に合う話題を加点。通年ネタは中立 |

## 落とす条件（関門）

1. `gate_blockers` がある（骨格の事実を一次資料で確認できない見込み、など）
2. 既存動画とほぼ同じ話（重なり 0.5 以上）
3. 資料の点が3以下は「要確認」と表示（落とさないが、採用前に必ず確認）

## 使い方

1. 公開後、Studio の再生数・視聴維持率を `channel_profile.json` に追記する
2. `topic_pick.py --month <公開したい月> --write docs/themes/<日付>_next/04_scores.md`
3. 上位3案に、`docs/THEME_SELECTION_PROCEDURE_V2.md` の関門（一次資料の確認）をかける
4. 決定は人。採用した題は `channel_profile.json` に追記し、候補から外す

## 限界

- 候補の各点は、Claude の事前の見立て。実際の需要（検索数・競合）は反映していない。`02_demand.md` のように、人が調べた数字を `hook` の点に反映する。
- 再生数がまだ少ないため、実績の項は当面ほぼ中立。公開が進んだら効いてくる。
