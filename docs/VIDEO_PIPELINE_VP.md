## 流れ（1本あたり）
1. 資料を読み、`docs/themes/<日付_slug>/08_fact_check.md`（主張ごとの根拠と原文）、`07_brief.md`、`09_script_v1.md`（番号つきの行がナレーション。〔Kn〕は根拠）を書く。
2. `codex_review.py ... script` → 指摘を原典で検証 → `09_script_v2.md`、`10_review_log.md`。
3. `data/<slug>_spec.json`（画面の定義）を、`scripts/make_spec_<slug>.py` で書く。`data/<slug>_pronunciations.json`（読み）。`data/<slug>_pronunciations.json` は `vp.py <slug> kana` で、実際の読み（kana）を確認する。
4. `vp.py <slug> story|kana|audio|bgm` → `vp.py <slug> ends`（文ごとの開始時刻）→ `vp.py <slug> still <秒>...`（レイアウト確認）。
5. `vp.py <slug> build`（`chunk=2000` フレームに切って並列レンダリング → 結合 → loudnorm → BGM → `qa`。黒フレーム・長さ・音量を検証）。**並列は3本まで**（10本で回すとGPUセッションが足りず `AssertionError: part render failed`）。**時間のかかるビルドはバックグラウンドで**回す（前景で1本の `part` を回すと、ツールのタイムアウトで切られて `moov atom not found` になる）。
6. `vp.py <slug> desc|thumb`、Codexで動画の査読 → 反映 → 再ビルド → `vp.py <slug> pack`（`upload/<番号_名前>/`）。

## 画面の部品（spec の `t`）
`panel`（枠＋文章）、`stack`、`cols2`（左右2列）、`chips`、`big`、`table`、`bars`（横棒）、`line`（折れ線。年に比例）、`daybar`（1日の帯）、`swirl`（渦の概念図）、`flow`、`timeline`、`image`（静止画。`cap` で見出し、`note` で注記＝`note_y` で位置）、`art`（章の背景イラスト。`shade` で後ろを暗くする）、`anim`（`scripts/vp_anim.py` の**動く図**。`name` で関数を選ぶ）。出現は文番号 `at`、消えるのは `until`。章冒頭のカードは `opener`。はみ出しは `assert` で止まる。

`anim` の書き方は「**語りに合わせて動かす**」が basic。関数は `vp_anim.DRAW` に登録した名前で呼ばれ、引数は `(im, d, cx, it, a)`。`it` は spec の項目そのもの（`box`・`at`・任意のキー）、`cx` は文の時刻（`cx.st[i]`＝文 i の開始秒、`cx.segl[i]['duration']`＝長さ）、`a` は出現のフェード。**動きの区間は秒ではなく文番号で書く**（`legs=[[i0,i1]]`＝文 i0 の開始から文 i1 の開始まで）。台本を直しても時刻が自動で追従する。

## 追記（2026-10-18、第3弾の5本で増えた道具と学び）
- **道具**：`scripts/codex_thumb.py <slug> "<場面>"`（サムネ背景を Codex の画像生成で作る）／`scripts/codex_watch.py <slug> [<テーマ>]`（Codex の通し視聴。4秒おきの静止画＋字幕＋音声の測定値）／`scripts/codex_kana.py <slug> [<テーマ>]`（VOICEVOX の読みをカナにして Codex に誤読を探させる）／`scripts/finish_video.sh <slug> <テーマ>`（build→desc→thumb→pack→通し視聴→読み確認）／`scripts/make_short.py`（縦型Shorts）／`scripts/yt_api.py`（API で非公開アップロード）。
- **静止画の時刻**：ffmpeg の `fps` フィルタは時刻が約2秒ずれ、「字幕が先に出る」という偽の指摘を生んだ。**フレーム番号**で切り出す（`select='not(mod(n,N))'`）。
- **読み辞書の落とし穴**：カタカナを入れると、かえって誤読になる語がある。`水平な成分→スイヘイナセイブン` は「スイエイナ」に、`航空宇宙局→…キョク` は「キヨ'ク」になった（漢字のままのほうが正しく読めた）。辞書を足したら、必ず `vp.py <slug> kana` で読みを確認。`明治四十二年` は `明治42年` と数字に直すと「メイジヨン」を避けられた。`二分は→ニフンワ`、`原論文→ゲンロンブン`、`時刻表`、`語が→ゴガ`、`後の研究→ノチノ` のように、同音異義は前後の語ごと指定する。
- **字幕の数字変換**（`scripts/hn_text.py`）：『不十分』が『不10分』になる不具合を直した（`不十分・十分に・十分な` は変換しない）。`一・四倍` や `八十五・八度` のような中黒の小数も算用数字に直す。
- **画面の部品**：枠にタイトルを付けると高さが要る。高さ112未満は、タイトルを本文に合流させて1行にする（各 `make_spec_*.py` の `_fit`）。`assert` が出たら、まず `vp.py <slug> still <秒>...`（ `ends` の時刻）で全場面を試し描画して、直す。
- **台本の査読で多かった指摘**：条件の落ち（「距離を同じとして…」の前提が、後半の別の比較にまで掛かる）、基準の年・時点、帰属（「〜と説明している」）、「最高」の意味、年齢と年号の整合（資料自体が食い違うことがある）。結論では、数字ごとに条件を言い直す。
- **VOICEVOX**：長時間の作業中に止まることがある。`curl http://127.0.0.1:50021/version` で確認し、止まっていたら `tools/voicevox/windows-cpu/run.exe --host 127.0.0.1 --port 50021` を起動する。
- **投稿**：API の動画ファイル差し替えはできないので、直したら `yt_api.py upload <パック> --new-version`、旧版は `delete-superseded`。公開予約は Studio（時刻の入力は、入力後に画面で確認する。入らず 0:00 になったことがあった）。

## 追記（2026-10-20、地図の上で軍勢を動かした回で増えた道具と学び）

- **地図の上の座標は、地図を作った式から取る**：`oke_maps.py` に切り出し条件の表 `MAPS` と `map_at(name)` を置き、`make_spec_*.py` がそれを import して正規化座標（左上0,0〜右下1,1）を作る。**画素を手で打たない**ので、地図を作り直しても印の位置が合う。確かめ方は「出来ているPNGに `map_at` の点を打って、地図の印と重なるか」を目で見る（座標の式を触ったら必ず）。
- **`anim` で軍勢を動かす型**：`vp_anim.oke_march`。spec は `dict(t='anim', name='oke_march', img='march', box=[...], at=0, armies=[dict(col=(255,150,90), pts=[...], legs=[[0,1],[11,12]])])`。`pts` は通過点（正規化）、`legs[k]=[i0,i1]` は「文 i0 の開始から文 i1 の開始までに pts[k]→pts[k+1] へ」。区間の外は通過点で止まる。
  - **1軍につき印は1つ**。区間ごとに印を分けると、待機中の印と動いている印が並んで「軍が分裂した」ように見える（実際に一度そうなった）。1本の折れ線＋区間の予定表にした。
  - **区間は重ねない**。前の区間の終わりと次の区間の始まりを同じ文にすると、切り替わりで印が飛ぶ。
  - **画面外から来る軍は、地図の縁で切る**。駿府の座標をそのまま入れると、見えない区間が全体の大半を占め、見えている範囲を一瞬で通り過ぎる。
  - 通った道すじは明るい線で残し、地図の破線（予定の道）は下に残す。**印と道すじは地図の矩形でクリップする**（枠全体に描くと、地図の外の余白にはみ出す）。
- **地図に文字を足すときは、動く印の通り道を見る**：ラベルの上を印が横切っていたら、ラベルを動かす（行軍図の「桶狭間」は印の左へ、「沓掛城」は印が下を通るので上へ移した）。**止まっている絵だけで確かめない**：動き出す前と後で同じ場所の絵を切り出して見比べる。目的地が無名のままだと読み違える（織田軍が着く「善照寺砦」を足した）。
- **複数の説がある図では、軍を動かさない**：周辺図は「桶狭間山はどこか」を見る図で、候補地が複数ある。軍の矢印を1本入れると「その候補地へ攻めた」と一つの説を選んだことになる。動かしたのは行軍図だけ。
- **座標の但し書きは強める**：大字の代表点は史跡と67m〜2.1kmずれる（`docs/themes/20261019_okehazama/08f...`）。地図の注記と概要欄に「数百メートルから1キロメートル以上ずれることがある」と書く。
- **「これからの宿題」を画面に出さない**：原史料を翻刻で確認したあと、章9の「原史料の確認は、これからの宿題」は事実でなくなった。**作業の予定を画面に書かない**（視聴者に意味がない）。
- **どの章にも図を入れる**：文字だけの章が続くと「読み上げ」に見える。`art`（背景イラスト）を敷くときは `box=[60,170,1860,850]`・`dim=1.0`・`drift=36`・`shade alpha=0.48`・`note_y=100` が読みやすさの目安（暗くしすぎると濁る）。
- **原史料・専門書・座標の確認を、作業として先に置く**：`08_fact_check.md` の主張のうち、原史料の語に触れている箇所は**公開されている翻刻**で照合する（今回2件の誤りが出た）。座標は国土地理院の住所検索APIと史跡の座標を突き合わせ、**ずれの大きさを数字で**残す。

## 追記（2026-10-21、お米・標準時・GPSの3本で増えた学び）
- **slug に下線を入れない**：`vp.py build` の結合が `cache/<slug>_part_<開始>_<終了>.mp4` を `_` で分けて番号を読むため、`akashi_time` は `ValueError`（`int('part')`）で止まった。`akashi` に改名（assets・data・out・スクリプトをまとめて）。
- **spec の `bgm`** は `[開始章key, 終了章key, 曲名]`（章の範囲）。ムード名を書くと `KeyError`。
- **`at` は台本の行ではなく「文」の番号**（`。` で区切る）。行を変えたら `vp.py <slug> sents` で番号を確かめてから spec を書く。
- **「≒」はフォントに無く、豆腐になる**。「＝約」と書く。
- **ビルドは単独か2本まで**：3本同時に別プロセスで回すと `part render failed [0, 1, 0, 0]`（GPUセッション）。**表の行が増えて枠を越えると、`still` では `AssertionError`、`build` では同じ `part render failed` になる**ので、`still` で全時刻を試し描画して原因を見る（`vp.py <slug> still 70 80 90 …`）。
- **バックグラウンド実行**：`cmd &` を入れ子にしたツール呼び出しは、呼び出しが終わると子が消える。長い作業は `run_in_background` で、コマンド列を `;` でつなぐ。
- **ChatGPT（web）の画像生成**：同じ会話に続けて頼むと画風が揃う。保存は、ページ内で `fetch(blob:…)` → `<a download>` → `~/Downloads` から移す（localhost へのPOSTはCSPで不可）。会話の古い画像はDOMから消える（最後の1枚を取る）。画像が生成済みでも、ブラウザのタブグループが消えたら会話URLを開き直して取る。
- **YouTube API がIPv4で届かない**：`curl -4` 不達・`curl -6` 到達。`socket.getaddrinfo` をIPv6固定にして `yt_api.py` を実行（スクリプトは書き換えない）。
- **Codexの指摘の裏取り**：「二百キロ→ニヒャッキロ」は誤りではない（促音便が普通）。「候補を→コ'オホオ」は「コーホ＋を（オ）」で、誤読ではない。**読みの指摘は、日本語として確かめてから反映**。
- **査読で見つかった重大な誤り**：ChatGPTの査読で、新聞の要約を鵜呑みにした記述（「1884年の会議が15度刻みの標準時を決めた」）が誤りと分かった。**議事録の原文（Project Gutenberg）で決議を読んで確認**。二次資料の要約は、原典で確かめるまで使わない。数字も同じで、農水省の食料需給表は、**最新の版（令和7年度）に更新されていた**ので、日付つきで最新を探す。

## 台本の型（`09_script_v2.md` の書き方）

型の正本は `docs/templates/09_script_v2_template.md`。新しい題材はこれを複製して書き始める。
下の5つは、**書き終えてから直すのではなく、最初から守る**（`scripts/qa_lint.py` が見るのは、このうち 1・2 だけ）。

1. **冒頭3文で結論を出す**。1文目で問い、2文目で答え（または「分かること／分からないこと」の枠）、3文目で「この動画で何を確かめるか」。引っぱらない。答えを先に言っても、理由と出典で見せれば退屈にはならない。
2. **1章＝1つの問い、180〜220字（読み上げ40〜50秒）**。260字を超えたら章を割る。逆に 90 秒を超える章は、視覚変化が4回以上ないと「止まって見える」（`qa_lint.py` の章チェック）。
3. **章末に、次章への引きを1文**（15〜30字）。「では、なぜそうなったのか。」「ここで、一つ引っかかる。」次章の1文目は、その引きを受けて始める。章をまたぐ接続が、通しで聴いたときの理解を作る。
4. **1文は40字以内、1行1文**。読点は1文に2つまで。数字は算用数字で書き、単位を添える（`hn_text.display()` が字幕・概要欄で変換する。ことわざ・地名・時刻の呼び名は漢字のまま）。
5. **最後の章は「分かること」と「決められないこと」を分けて締める**。決められないことは、決められない理由（資料がない・説が割れている）まで書く。断定を避けるのではなく、**どこまで言えるかを言い切る**。

- 各文の末尾に出典タグ（`〈C3〉` など）を置く。タグの対応表は `08_fact_check.md` の「主張 → 出典」にある。

## 字幕のタイミング（2026-10-22 追加）

字幕を出す・消す時刻は、**文字数で按分しない**。`vp.py` の `stage_audio` が音声から無音（息継ぎ）を検出し、境界をそこへ寄せる（`_cue_times`）。

- 手順：10ms フレームの RMS を出し、**発話区間の中央値の 8% を下回る 0.12 秒以上の区間**を無音とみなす → 文字数按分の境界から **0.5 秒以内**の無音へ寄せる。無音が無ければ**音量の谷**（±0.35秒）、それも無ければ比例位置のまま。
- 上下限：ずらす量は 0.5 秒まで、字幕は最短 0.45 秒。無音は**1つずつ順番に**割り当てる（2つの境界が同じ無音を取り合わない）。
- 結果は `out/<slug>_audio_report.json` の各 segment の `cue_times`（と `pauses`）に入り、**SRT と焼き込み字幕の両方**が同じ配列を使う。移動量の記録は `out/<slug>_subtitle_timing.json`。
- 実測（oke・calendar・einstein・islands・moon の計38境界）：境界の音量（発話中央値比）は **0.61 → 0.04**、無音に着地した割合 **61% → 97%**、移動量の最大 0.46 秒。
- 既存動画に後から当てるときは `python scripts\vp.py <slug> audio`（音声はキャッシュ済みなので合成しない。`narration.wav` と尺は変わらない）。字幕が変わるので `build` で焼き直す。
- `qa_lint.py` の文字数/秒（CPS）は字幕テキストと区間で計算するため、境界が動いても値はほぼ変わらない（oke は 5.15 字/秒のまま）。
