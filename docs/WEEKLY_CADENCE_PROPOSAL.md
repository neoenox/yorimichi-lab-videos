# 公開ペースの見直し案（長尺を週2〜3本、Shortsは毎日）

状況: 予約は 2026-10-21〜2027-02-15 に約190件。11月の第2〜4週に、長尺が週8〜17件ほど集中している（YouTubeの実際の予約から集計。長尺/Shortの判定は動画の長さの概算）。
登録者8人・Shorts約1,200回/長尺ほぼ0 の段階では、毎日長尺を出しても1本あたりの初速が分散する。

## 案
- 長尺: 火・木・土の19:00（週3本）。迷うなら火・土の週2本から。
- Shorts: 毎日20:00。長尺の公開日は、その長尺の切り抜きShortで誘導する。
- 長尺の順番: 戦況解説（歴史）と一般題材を交互に並べ、同じ分野を続けない。
- 12月以降に溜まっている長尺は、上のペースで後ろへ詰め直す。公開が延びる分は、金曜の空きを単独Shortで埋める。

## 実施するとき（ユーザーの許可が必要）
1. 現在の予約一覧を `yt_api.py stats` で取り、公開日順に並べる。
2. 上のペースで新しい日時を割り当て、一覧を確認してもらう。
3. 許可後に `yt_api.py schedule <id> <日時>` で付け替える（1件50ユニット、1日の上限10,000）。

まだ予約は一件も変えていない。
