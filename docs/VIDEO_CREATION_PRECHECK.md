# 動画制作前の必須確認

更新日：2026-11-03

**動画を作り始めるすべてのエージェントは、この文書を作業開始前に全文確認してください。** 親エージェントの確認だけで委任先の確認を代替しません。プロジェクト共通の必読指示はルートの [`AGENTS.md`](../AGENTS.md) にあります。

この確認票は、動画の新規制作、改訂、シーン・素材・台本同期・字幕・音声の作成、レンダリングを始める前に使います。レビューだけの依頼では、制作へ進む前に確認してください。

## 作業開始前の確認

- **今回伝えることを一文にする。** 台本やナレーションを時間順に区切り、各区間で視聴者に何を見せるか決める。説明と画面の変化を同じ順番にする。
- **工程ものは一段ずつ見せる。** まず基準になる状態を見せ、次に変化する場所を一つだけ加える。前の変化を残して積み重ねる場合は、その意味が分かるように色・凡例・短い説明を揃える。
- **動きに読む時間を含める。** 図が変わる時間だけでなく、変化後に内容を理解する静止時間を設ける。銀座試作の目安は1段階約1.8秒で現れ、次の段階まで約1.6秒保持（約3.4秒間隔）。これは設計の出発点であり、全動画に適用する固定値ではありません。説明の長さ・情報量・ナレーションに合わせて決めます。
- **説明中のカメラを落ち着かせる。** 大きく移動・ズームするのは場面への導入や離脱に寄せ、複雑な地図を読む間はカメラを止めるか、非常にゆっくり動かす。動きが理解を妨げるなら、動きを減らして保持時間を増やす。
- **関連要素を同じ座標変換で動かす。** 地図、歴史レイヤー、境界、地点印、ラベル、指示線を個別に動かさず、共有する地理座標・カメラ変換・シーン変換を使う。座標変換を変えたら代表地点で重なりを再確認する。
- **ラスタ素材の範囲を確認する。** 最大ズームと移動先まで素材が届くか、余白・黒帯・切れ・タイル境界が出ないか確認する。元画像の範囲が足りない場合は、安易に拡大や位置ずらしで隠さず、素材範囲かカメラ経路を直す。
- **スマホ表示で要点を読めるようにする。** 地図の細かな文字や注記を増やしすぎない。主題・地名・凡例・出典の優先順位を分け、320×180相当でも意味が残るか確認する。
- **根拠と演出を分ける。** 地図や歴史的範囲が模式図・推定・復元の一例なら、画面にもその限界を短く表示する。素材の出典、利用条件、必要なクレジットを制作記録と概要欄に残す。
- **元成果物を守り、版を分ける。** まず別名の短い試作で画面とペースを確かめる。依頼されていない完成候補を上書きしない。試作・編集版・完成候補・投稿済みを区別する。

## 書き出し後の確認

- 代表場面を時間順に並べ、変化の順番、保持時間、字幕と場面の対応、カメラの速度を確認する。
- 場面の前後、ズーム端、素材切替、画面端、テロップ出入りを静止画で確認する。抜き取り画像だけで連続した動きの滑らかさを保証しない。
- 外部AIの静止画レビューは指摘として扱い、対象画像とレンダーを照合する。ファイル名の番号を秒・フレームへ換算するときは抽出側の命名規則を先に確認する。自分の時刻説明が誤っていた場合は、訂正後の時刻で再評価を依頼する。
- 透過文字や重なりの指摘は、同じ場面の直前・登場中・完了後を続けて見る。カードの登場アニメーションと古い字幕レイヤーの残留を区別し、見えている現象と原因を混同しない。
- 最終候補をプレーヤーで連続再生し、実際の見え方を確認する。動画全体のデコード確認と、視聴品質の確認は別の結果として記録する。
- 音声付き動画は、ナレーション全編を実際に聴く。読み、音切れ、ノイズ、BGMとのバランス、字幕との同期を確認する。LUFS・ピーク・デコード検査だけで聴感確認を代替しない。
- 報告では、技術検証、連続視聴、全編の聴取、史実・出典確認、スマホ実機確認を別々にし、未実施の項目を完了扱いにしない。
