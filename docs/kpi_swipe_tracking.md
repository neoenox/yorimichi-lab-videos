## 決めたこと（2026-11-18）
- 最優先の指標は **スワイプ率**（入口でどれだけ離脱されるか）
- 判定：**スワイプ率が同種の過去動画（81〜82%）から3ポイント以上下がる**、または**平均視聴率が45%を超える** → 型を標準化する
- それ以外なら、型は標準化せず、別の原因（題材・尺・画面）を疑う
- 判定は **11/26**（2026-11-20 のオーナー判断で 11/20〜21 から後ろ倒し）。発電ショートは 11/24 公開で、その数字は 11/26 以降にしか取れない。**n=2 が揃うまで判定しない**。閾値は変更しない

## 取り方（手順）
1. Studio → アナリティクス → コンテンツ → 該当動画 → 「ショート動画」の分析でスワイプ率・視聴を継続率を見る
2. 平均視聴率は、Analytics の「視聴率」またはAsk Studioで確認（1〜2日遅れ）
3. 数字をこの表に記入し、上の判定基準に当てはめる
4. 判定と理由をメモリと手順書に記録する
