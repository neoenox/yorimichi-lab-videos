## 0. 結論（先に3行）

1. **TikTokはYouTubeの代替ではなく「発見エンジン」と「フックの実験場」として使う。** YouTube長尺はインプレッション0で、タイトル・サムネの良し悪しが測れない段階。TikTokはフォロワー0でもテスト配信される数少ない面です。
2. **既存のShort 66本をそのまま出さない。** 「結論を0秒に置く・登録/概要欄CTAを消す・BGMを変える・21〜34秒に詰める」再編集をした**15本だけ**を5週間で試し、数字で柱を1つに絞る。
3. **アカウントは一般（個人）で開始。** ビジネスアカウントはプロフィールにリンクを置ける代わりに、Creator Rewards（収益化）の対象外になる。フォロワー0ではリンクの価値より、将来の選択肢を残すほうが大きい。

## 2. 戦略

### 2.1 3つの役割

```
TikTok（発見・実験）
   │  どの題材・どのフックが3秒で止まるか
   ▼
型の発見（数字／反転／問い）
   │  当たった型だけを戻す
   ▼
YouTube長尺の冒頭・タイトル・サムネ（資産化）
```

TikTokを「本編の宣伝」に使うと、リンクが無い個人アカウントでは成果が出ません。**TikTokで当てた型をYouTubeに逆流させる**ほうが、このチャンネルの現状（長尺0再生）には効きます。

### 2.2 なぜYouTubeの改善より先にTikTokか

- YouTubeは**インプレッション0**。タイトル・サムネを直しても差が出ない（自分析の結論）。
- TikTokは**フォロワー0でもテスト配信**があり、維持率で拡大する（運用上の理解。最初の3本で検証する）。**測れる**。
- **追加取材がほぼゼロ**。長尺20本以上＋Short 66本＋検証済み台本が既にある。
- **予約125本が2027-02まで埋まっている**。3週間、新規制作を止めても公開は止まらない。制作時間をTikTokに回せる。

### 2.3 戦略上の除外（やらないこと）

- 66本の一括投稿（「未編集の再利用」に近づく。ブランドも散る）
- 毎日投稿（YouTubeの日刊と衝突する）
- 顔出し・トレンド音源・エンタメ寄せ（ブランドと権利の両方で不利）
- 画面内のYouTube誘導（「チャンネル登録」「概要欄」「サムネのリンクから」）
- 科学雑学（静脈・月・金星など）のTikTok展開 — **90日はやらない**。YouTubeに残す

## 4. コンテンツ設計

### 4.1 柱は3つに絞る（90日）

| 柱 | 使える素材 | TikTokとの相性 | リスク |
|---|---|---|---|
| **地形・地名**（本命） | 東京の低地4本（渋谷・日比谷・銀座・深川） | 「渋谷は海だった」が**1秒で伝わる**。地元コメント・検索需要 | 縦に作り直す手間（長尺は16:9） |
| **戦国**（対抗） | 10本（関ヶ原・桶狭間・三方ヶ原・賤ヶ岳・鳥取ほか） | 競合が多いが上限が高い。裏切り・結末の感情 | 「歴史解説」は供給過多 |
| **江戸の暮らし**（探索） | 20本以上（一刻・家賃・寿司・火消し・飛脚ほか） | 数字の意外さ。生活実感でコメントが付く | 地味。フック次第 |

**ブランドは「地図と史料で通説を確かめる」に寄せる。** 「雑学チャンネル」にすると、TikTokでは埋もれます。

### 4.2 1本の設計（21〜34秒）

| 秒 | 内容 | ルール |
|---|---|---|
| 0.0〜1.0 | 結論か数字 | 検証済みのものだけ。挨拶・チャンネル名は置かない |
| 1.0〜4.0 | 問い | 画面テキストに**検索語**を入れる |
| 4.0〜20 | 図で説明 | **1画面1論点**。文字は2行まで |
| 20〜30 | 答え＋留保 | 「ここまでは史料で確認」を一言 |

- **尺**：基本21〜34秒。既存Shortは40〜60秒前後・継続20〜32%なので、**言葉を削って短くする**（音声の速度は上げない）。
- **画面**：1080×1920／30fps。セーフエリアは x 60〜960、y 250〜1450（右のアイコン列と下のキャプションを避ける）。
- **音**：ナレーション＋BGMなし（またはクリア済みの極小）。ラウドネスは既存と同じ **-14 LUFS / TP -1.5**。
- **字幕**：焼き込み。自動字幕は固有名詞（地名・人名）に弱い。
- **ループ**：最後の1秒を最初の1秒に戻せる形にするとリプレイが取れる。

### 4.3 フック3型（各5本、数字は動画内で確認済みのものだけ）

| 型 | 例（既存の検証済み事実） |
|---|---|
| A 数字 | 「江戸の一刻は、夏と冬で47分違った」 |
| B 反転 | 「渋谷は、海だった」 |
| C 問い | 「関ヶ原は、本当に午後から決まったのか」 |

**新規の数字を作らない。** 出典は動画内と固定コメントに残す（このチャンネルの差別化そのもの）。

### 4.4 キャプションと検索

- 1行目に**検索語**（例：`関ヶ原 なぜ負けた`、`渋谷 海 埋め立て`、`江戸 一刻 時間`）。
- ハッシュタグは3〜5個（`#歴史` `#戦国時代` `#地形` `#東京` `#雑学`）。
- **固有名詞を冒頭で発音する**（TikTokは音声も検索対象）。
- YouTube型の「〜で確かめる」はTikTokでは弱い。**結果・数字を前に出す。**

## 5. 実験計画（15本・5週間）

**いきなり15本を作らない。** 6本で読み、残り9本の配分を変えます。

| 段階 | 週 | 本数 | 内容 |
|---|---|---|---|
| Stage 1 | W1〜2 | 6本 | 3柱×2本（#1〜6）。フック型はA/B/Cを1本ずつ |
| Stage 2 | W3〜5 | 9本 | 勝ち柱5本＋次点4本（#7〜15を入れ替え） |
| Stage 3 | W6〜12 | 24本 | 勝ち柱に80%を寄せる（週3本） |

### 判定（Stage 1の6本＋Stage 2の9本＝15本時点）

| 判定 | 条件 | 次の手 |
|---|---|---|
| **A 当たり** | 中央値 ≥ 1,000再生 かつ 最大 ≥ 10,000 | その柱に80%。型を固定して量産 |
| **B 拮抗** | 中央値 300〜1,000 | 柱は変えず、**フックだけ**作り直して+9本 |
| **C 不発** | 中央値 < 300 かつ 最大 < 3,000 | 柱を入れ替え。もう1回Cなら撤退 |

判定は再生数だけでなく、**3秒維持・完走率・共有/保存・フォロー/1,000再生**で見ます（再生数はTikTokでは広くカウントされるため、他社比較に使わない）。

## 8. 権利・クレジット・安全

| 対象 | TikTokでの扱い |
|---|---|
| VOICEVOX:四国めたん | 商用可・**クレジット必須**。bio＋固定コメント＋末尾に「VOICEVOX:四国めたん」 |
| 魔王魂 BGM | **TikTokでは使わない**。音源検出でミュートされうる。クリア済みBGMか無音にする |
| ChatGPT生成画像 | **AIラベルON**。生成記録（プロンプト台帳）は既存のまま維持 |
| 地理院タイル・Google Earth | 画面に小さく出典（既存踏襲）。Googleの必須表記は消さない |
| 肖像 | パブリックドメインのみ（既存踏襲） |
| 歴史の断定 | 「一説」「確認できた範囲」を維持。TikTokは誤情報通報が多い |
| 医療・健康 | Phase 1では扱わない（誤情報リスクが高い） |
| 子ども向け設定 | 対象外（年齢制限まわりの扱いを避ける。教育向けでも子ども向け指定はしない） |

**避ける語**：`チャンネル登録` `概要欄` `youtu.be` `高評価` `拡散希望`。書き出し前の自動チェックに入れる。

## 9. 実装（既存パイプラインの変更点）

| 変更 | 場所 | 内容 |
|---|---|---|
| TikTok用の終わり方 | `scripts/make_short2.py` | spec に `platform: "tiktok"` を追加。末尾を「本編の動画／概要欄のリンクから」から、**問いかけ＋出典**に差し替え |
| CTAの除去 | 同上 146行 | `cta:false` で読み上げから「チャンネル登録を」が消える（**再レンダリングが必要**） |
| BGMの切替 | `scripts/make_short.py` `mix()` | 魔王魂の固定パスを引数化し、`none` / `cleared` を選べるようにする |
| 書き出し | 同上 | 1080×1920／30fps／-14 LUFS／`+faststart` |
| 新規 | `scripts/tiktok_pack.py` | spec → mp4＋キャプション＋ハッシュタグ＋投稿メモを1回で出す |
| 検証 | 新規 | 尺・解像度・音声・禁止語・AIラベル・出典の有無を自動チェック |

既存の `draw_hook()`（結論を最初の1.6秒に出す）は**TikTok向き**なので、そのまま活かせます。変えるのは主に「尺・CTA・BGM・検索語」です。

**投稿は手動**（アプリ or Webの予約）。TikTokの自動投稿は公式APIの審査が必要で、エンゲージメント自動化は規約違反です。
