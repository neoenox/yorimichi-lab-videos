# ChatGPT（web）による動画レビューの記録

観点は一つ：「YouTubeの視聴に耐えうるクオリティになっているか」。動画を確認用に圧縮して添付し、6項目（冒頭30秒／映像の変化／文字の読みやすさ／ナレーション／BGM・音量／構成と離脱箇所）を良い・普通・悪いで判定してもらう。
ナレーションとBGMの聴感は、ChatGPTは聴けないため毎回「確認できず」。聴感は人（ユーザー）が確認する。音量の数値（ピークなど）は、圧縮で変わるので、元ファイルを ffmpeg の ebur128 で測り直す。

## 手順（これで再現できる）
1. 長尺は `ffmpeg -vf scale=960:-2 -r 4 -c:v libx264 -crf 34 -preset veryfast -c:a aac -ac 1 -b:a 40k` で10MB未満に（17分で約7.7MB）。3分前後なら 1280幅・15fps・crf27・128k（約6MB）。
2. claude-in-chrome の `file_upload`（10MB未満、作業フォルダ内のパス）で https://chatgpt.com/ の新規チャットに添付→プロンプト送信（送信は右下の橙の矢印を座標クリック）。
3. 回答まで約4〜7分。3本まで並列（別タブ）で送れる。

## 共通の指摘（戦況解説・長尺）
- 結論・目玉（新史料など）を冒頭30〜60秒に出す。時系列の説明は後ろか、検証に必要な分だけに絞る。
- 地図は画面いっぱいに拡大し、部隊の動きを数十秒ごとに切り替える。地図内の小さい文字は大きくする。
- 小さい説明帯・細い枠・年表の文字は、スマホで読めない。一画面一メッセージにする。
- 『分からないこと』『まとめ』は短く。
