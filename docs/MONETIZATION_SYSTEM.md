# 寄り道ラボ 収益化システム

作成：2026-11-24。上位方針は [CHANNEL_STRATEGY_20261124.md](CHANNEL_STRATEGY_20261124.md) 第9節。ここでは各収入源を「いつ導入するか」に沿って整理する。

現状（2026-11-24、API）：登録者60人、総再生82,022回、動画198本。直近28日は視聴回数72,366回、総再生時間291.9時間、登録者+54人、インプレッションCTR2.74%。Shortがほぼすべてを見ていて、長尺は198回・約3.5時間。**収益化の時間条件は長尺でしか積めない**。

## 0. 結論

順番は固定する。

1. まず長尺の維持率を直す。平均視聴が約1分のままでは、再生が増えても時間が積まれない。
2. 500人で早期アクセス、1,000人で本則。その前に広告以外の収入源は開かない。
3. 楽天アフィリエイトは再開しない。2026-11-16に別プロジェクトへ移設済み。
4. スポンサー・商品・講座は、要件を通過した後の選択肢として設計だけしておく。

収益目標額と期限は未設定（[CHANNEL_STRATEGY_20261124.md](CHANNEL_STRATEGY_20261124.md) の【 】）。以下は金額の予測ではなく、導入の順番と準備物を書く。

## 1. 成長段階の定義

| 段階 | 登録者 | ほかの条件 | 状態 |
|---|---|---|---|
| S0 | 〜500人未満 | 早期アクセス未達 | いまここ |
| S1 | 500人〜 | 90日で公開3本以上、かつ3,000時間（12か月）またはShort 300万回（90日） | 早期アクセス |
| S2 | 1,000人〜 | 4,000時間（12か月）またはShort 1,000万回（90日） | 本則 |

条件は2026-11-24に公式ヘルプで確認した内容。申請前にStudioの「収益化」で最新を再確認する。日本は早期アクセスの対象国。

## 2. 収入源ごとの導入時期

| 収入源 | 導入 | 理由 | 準備物 |
|---|---|---|---|
| 広告（長尺） | S2 | 本則の条件。Shortの視聴は時間に数えない | モジュール同意、AdSense |
| 広告（Short） | S2直後 | ショート収益化モジュールは本則後に同意する | クリエイタープール方式。1,000万回/90日が毎月の分配条件 |
| メンバーシップ | S1 | 早期アクセスで開く | 特典の定義。500人規模では金額は小さい |
| Super Chat・Stickers・Thanks | S1 | 早期アクセスで開く | 受け取る側の設定。贈る側の導線は動画内に置かない |
| ショッピング | S1 | 早期アクセスで開く | 商品の選定。このチャンネルでは未設計 |
| アフィリエイト（楽天） | 導入しない | 2026-11-16に別プロジェクトへ移設。このチャンネルでは再開しない方針 | — |
| アフィリエイト（書籍・史料） | S2以降、検討 | 歴史・地理の自然な導線になり得る。要件通過が先 | 対象書籍の選定、開示文、リンクの掲載位置 |
| スポンサーシップ | S2以降、検討 | 城・古戦場・自治体・書籍が自然な候補になり得る（[NICHE_AND_100_IDEAS_20261124.md](NICHE_AND_100_IDEAS_20261124.md) 5）。いまは当てにしない | 料金表、企画書、開示ルール、断り基準 |
| デジタル商品 | S2以降、検討 | 独自の地図・経路データという強みを商品にできる | 商品定義、権利確認、配布先 |
| 講座 | S2以降、検討 | 顔出し・声出しなしの運用と相性を確認してから | カリキュラム、平台、サポート範囲 |
| ニュースレター | S1以降、任意 | 登録者へ次の動画を知らせる導線。収益直接よりリピーター目的 | 配信媒体、頻度、オプトインの導線 |
| コミュニティ投稿 | S0から可能 | 収益ではなく、登録者との接点とリピーター形成 | 投稿の型、返信のルール |

S0で開くのはコミュニティ投稿だけ。ほかは要件通過後の話として設計を置く。

## 3. YPP申請の準備

### S0でやること

1. Studioの「収益化」で現在の条件と達成状況を確認する。公式条件は変わるので、2026-11-24の記録を正としない。
2. 2段階認証、AdSense連携、違反警告の有無、上級者向け機能の設定を確認する（[CHANNEL_STRATEGY_20261124.md](CHANNEL_STRATEGY_20261124.md) 9-1 段階0）。
3. 動画の范围是「歴史×地理」に絞る。チャンネル説明文の「何でも調べる」は残してよいが、動画の実態とのずれは審査で不利になる。
4. 再利用コンテンツと見なされない材料を揃える。地図・経路・距離は自分で計算し、概要欄に出典を書く。台本は自作（同 9-4）。
5. 同じ型の量産と見なされないよう、柱ごとに画風と構成を変える（[PRODUCTION_CYCLE.md](PRODUCTION_CYCLE.md)）。
6. 権利台帳を維持する（[HONNOJI_RIGHTS_LEDGER.md](HONNOJI_RIGHTS_LEDGER.md)）。
7. 6か月の無投稿で収益化が無効になる場合があるため、長尺の公開を止めない。

### 申請時

- 早期アクセスは500人＋90日3本＋3,000時間またはShort 300万回。本則は1,000人＋4,000時間またはShort 1,000万回。
- 審査は通常1か月。落ちたら21日以内に再審査請求、または30日後に再申請（[CHANNEL_STRATEGY_20261124.md](CHANNEL_STRATEGY_20261124.md) 9-1）。
- 申請はYouTube側の操作なので、エージェントが代行しない（[CHANNEL_SETUP.md](CHANNEL_SETUP.md)）。

### 権利の未確認を先に潰す

- BGMは魔王魂。商用・収益化可だが、動画内または概要欄に「音楽：魔王魂（曲名、作曲：森田交一）」の表記が必要（[HONNOJI_RIGHTS_LEDGER.md](HONNOJI_RIGHTS_LEDGER.md)）。
- 国土地理院の空中写真とタイルは出典明示のみで申請不要だが、**収益化YouTube動画での扱いに直接の記載が無い**。公開前に審査係へ問い合わせる予定が残っている（[themes/20270609_shibuya_river/09_script_v2.md](themes/20270609_shibuya_river/09_script_v2.md)）。これが未解決のまま収益化を通すと、過去動画の取り扱いが問題になる。
- 肖像・錦絵はWikimedia Commonsで所蔵・作者・年代・PD表示を記録する。国ごとの制限を再確認する（[VIDEO_PRODUCTION_RUNBOOK.md](VIDEO_PRODUCTION_RUNBOOK.md)）。
- 生成AIの映像・画像は「AIの使用＝はい」と概要欄に明記する。

## 4. AdSense戦略

- 広告収入の中心は長尺。Shortsの分配はクリエイタープール方式で、1,000万回/90日が毎月の分配条件。当面は金額を当てにしない。
- 本則通过后、動画の広告設定とショート収益化モジュールの両方に同意する。
- 長尺の平均視聴を3か月で3分、6か月で6分に上げることが、広告時間を増やす前提（[CHANNEL_STRATEGY_20261124.md](CHANNEL_STRATEGY_20261124.md) 8）。
- 必要な再生数は平均視聴時間で変わる。平均6分なら3,000時間は30,000回、4,000時間は40,000回。平均2分ならそれぞれ90,000回、120,000回。**維持率が先、再生数が後**。
- 最初の関門は長尺の中央値500回。超えたら2,000回を狙う。

## 5. S1で開くものの設計

### メンバーシップ

- 500人規模では金額は小さい。通過点として扱う。
- 特典は「地図・経路の元データ」「出典リスト」「先行公開」のような、このチャンネルの強みに沿うものに限定する。顔出し・声出しはしない方針を崩さない。
- 価格と特典の詳細は未設定。導入時に決める。

### Super Thanks

- 動画内で贈るよう促す文は置かない。約束は「地図と史料で通説を確かめる」で、投げ銭を前面に出すと信頼を削る。
- 概要欄に静かに設置する程度に留める。

### ニュースレター

- 目的は収益ではなくリピーター。登録者に次の動画を知らせる導線としてS1以降に任意で入れる。
- 配信媒体・頻度・オプトインの導線は未設定。

### コミュニティ投稿

- S0から使える。投稿の型と返信ルールは未設定だが、YouTubeコミュニティの投稿機能で始められる。
- 動画の補足、出典の追加、次回の予告に使う。誤情報の訂正にも使う。

## 6. S2以降の検討事項

いずれも「要件通過後の選択肢」であって、いま導入するものではない。

### アフィリエイト（書籍・史料）

- 楽天は別プロジェクトへ移設済みで再開しない。
- 歴史・地理の動画なら、使った史料の書籍を紹介する導線は自然。ただし買うことを勧める表現は避け、出典の一部として置く。
- 開示文（アフィリエイトリンクを含む旨）を概要欄に書く。報酬のために結論を曲げない。
- 対象書籍の選定とリンク生成は未実施。

### スポンサーシップ

- 自然な候補は城・古戦場・自治体・書籍（[NICHE_AND_100_IDEAS_20261124.md](NICHE_AND_100_IDEAS_20261124.md) 5）。ただし要件通過が先で、当てにはしない。
- 料金表・企画書・開示ルール・断り基準は未作成。
- 受ける場合でも、史料の解釈をスポンサーに合わせない。これはチャンネルの約束に関わる。

### デジタル商品・講座

- 独自の地図・経路・距離の計算は商品になり得る。ただし権利確認（国土地理院、肖像、BGM）を通してから。
- 講座は顔出し・声出しなしの運用と相性を確認してから。配信先・カリキュラム・サポート範囲は未設定。

## 7. 収益化までに潰すリスク

| リスク | 判定 | 対処 |
|---|---|---|
| 長尺が伸びない | 3か月で中央値500回に届かない | 関連動画の設定漏れを先に疑う。次にタイトルを数字型へ |
| 時間が積まれない | 平均視聴が約1分のまま | 冒頭15秒に数字、30秒以内に図。維持率を先に直す |
| 再利用と判定される | 独自計算と出典が薄い動画 | 地図・経路・距離を自作し、概要欄に出典。台本は自作 |
| 量産と判定される | 同じ型が続く | 柱ごとに画風と構成を変える |
| 権利の問題 | 表記漏れ・未確認データ | 権利台帳を維持。BGM表記を入れる。地理院の収益化扱いを問い合わせる |
| 無投稿 | 6か月空く | 長尺を週2本止めない |
| 審査不承認 | 21日以内に再審査請求、または30日後に再申請 | 独自計算と出典を強化する |
