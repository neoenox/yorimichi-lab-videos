## 推薦（作る順）

### 1. 冬至は、一年でいちばん寒い日？｜気温の底は約1か月半あと
- **掴み（0:00-0:20）**：「一年で昼が一番短い日＝一番寒い日、だと思っていませんか。実際の気温の底は、冬至から約1か月半あとです。」
- **確かめること**：冬至＝太陽高度が最低・昼が最短は事実。だが気温の最低は1月下旬〜2月上旬（地面が冷えきるまで時間がかかる）。「一番寒い」を日平均・日最低・月平均のどれで見るかで答えが変わることも示す。
- **一次資料**：気象庁「日本の気候」平年値（東京の月別気温）、国立天文台 暦計算室の二十四節気。グラフは平年値から自作。
- **画面**：日照時間の曲線と気温の曲線を**同じ横軸に重ね、ピークがずれる**のを見せる。既存の `season` / `sunrise` の作図部品を流用できる。
- **枠・接続**：12/19 か 12/20（冬至の直前）。`season` → `calendar` → `sunrise` の暦シリーズに接続。
- **関門**：「一番寒い」の定義を先に固定しないと、結論が地域・指標でぶれる。東京の平年値に限定して言う。

### 2. 江戸の範囲は、今の東京のどこまでだった？｜朱引線を現代地図に重ねる
- **掴み（0:00-0:20）**：「『江戸』と書いてある地図の範囲は、今の東京のごく一部です。境界線には、朱で引いた線がありました。」
- **確かめること**：江戸の町奉行支配の範囲は朱引で示され、その外は代官支配など別の支配。朱引の内側が現在のどの区にあたるかを、現代地図に重ねて示す。
- **一次資料**：東京都公文書館所蔵「江戸朱引図」、国立国会図書館デジタルコレクションの江戸切絵図。作成年・作図者は要確認。
- **画面**：**日比谷・銀座・深川で作った「現代地図＋地理座標の重ね合わせ」をそのまま使える**。朱引の内側を淡い色で塗り、区境を薄く重ねる。面積は地図から計算して数字で出す。
- **枠・接続**：12/10 か 12/13。`tokyo_lowland`（日比谷→渋谷→銀座→深川）の集大成として「範囲」を見せる。
- **関門**：朱引＝行政境界であって「人が住んでいた範囲」ではない。この区別を画面に明記する。

### 3. 日本の川は、なぜ短くて急なのか？｜信濃川と世界の川を同じ縮尺で比べる
- **掴み（0:00-0:20）**：「日本一長い信濃川でも、世界では100位より下です。長さより効くのは、勾配です。」
- **確かめること**：日本の川は長さが短く勾配が急、という一般に言われる特徴を、国土交通省の比較資料の数字で確認。源流から河口までの標高差を同じ縮尺のグラフにして、ナイル・アマゾン・ライン川と並べる。
- **一次資料**：国土交通省「日本の川」「世界の川」、国土地理院の標高データ。
- **画面**：横軸に距離、縦軸に標高をとった**縦断勾配グラフ**を自作。地図は使わず、グラフと写真で見せる（地図疲れの回に挟む）。
- **枠・接続**：12/6 か 12/8。`gm`（地図の大きさ）・`islands` と同じ「数字で比較する」型。
- **関門**：順位は資料の版で変わる。**「何年版の数字か」を画面と概要欄に書く**。

### 4. 高天神城は、なぜ武田の救援が来ないまま落ちたのか｜天正9年、遠江の飛び地
- **掴み（0:00-0:20）**：「遠江の高天神城は、武田の飛び地でした。徳川に囲まれたとき、勝頼は救援を出せませんでした。落城は、武田家の求心力を削ります。」
- **確かめること**：天正9年（1581）3月の高天神城落城を、攻める側（家康・信長）と守る側（岡部元信）の記録から確認。救援が出なかった理由を、勝頼側の事情と合わせて**説を並べる**（断定しない）。
- **一次資料**：『信長公記』天正9年3月の高天神城落城の条、『三河物語』、『甲陽軍鑑』（後世の軍記であることを明記）。
- **画面**：遠江の地図に、高天神城・掛川城・諏訪原城などの支城を置き、**補給線が切られていく過程**を既存の `vp_anim` で動かす。肖像は岡部元信・武田勝頼・徳川家康。
- **枠・接続**：12/3 か 1/9。`mikatagahara` → `nagashino` → 高天神城で「家康と武田」の3部作になる。
- **関門**：落城の日付と経緯は史料で差がある。`08_fact_check.md` で諸説表を作ってから台本に入る。

### 5. 「させていただきます」は、正しい敬語？｜文化庁の指針で条件を確かめる
- **掴み（0:00-0:20）**：「『させていただきます』は、目上の人に使うと失礼——本当にそうでしょうか。文化庁の指針は、条件つきで認めています。」
