# 検証用の背景イラスト：ChatGPT（web）への依頼文

3枚を**同じ会話で続けて**頼む（画風がそろう）。保存先 `assets/sigcmp/`。文字は入れさせない。サイズは横長16:9。

## 1枚目 `art_intro.png`
```
動画の背景に使うイラストを作ってください。横長（16:9）、文字・数字・ロゴは一切入れないでください。
場面：夜の日本の交差点。歩行者用ではなく、道路の上に下がった車用の信号機が手前にあり、光っているのは「青信号」のランプです。
そのランプの色は、青というより、青みのある緑（ターコイズ寄り）にしてください。
全体は、やわらかい色合いのフラットなイラスト風。濃い紺の夜空と、街灯のあたたかいオレンジ色の光を対比させる。
画面の中央と下側は、あとで文字をのせるため、細かい書き込みを避けて、暗めで落ち着いた空間にしてください。
```

## 2枚目 `art_law.png`（同じ会話で続けて）
```
同じ画風で、もう1枚。横長（16:9）、文字・数字・ロゴは入れないでください。
場面：信号機の青信号のランプのアップ。ランプは、青みの強い緑色（ターコイズ寄り）に光っている。
そのまわりに、法律の本や条文を思わせる、読めない記号のような線の束（文字にはしない）を、うっすらと浮かべる。
背景は暗い紺。中央と下側は、文字をのせるため、すっきり空けてください。
```

## 3枚目 `art_world.png`（同じ会話で続けて）
```
同じ画風で、もう1枚。横長（16:9）、文字・数字・ロゴは入れないでください。
場面：やわらかい色の世界地図。日本、韓国、ベトナム、イギリス（アメリカでも可）あたりに、色とりどりの空の吹き出し（中は空白）を置く。
吹き出しの色は、青、緑、青緑を混ぜる。国境線や地名の文字は入れない。
背景は暗めの紺で、中央と下側には、文字をのせるため余白を残してください。
```

## 受け取ったあと
1. 3枚とも、画像の中に文字が入っていないか確認する（入っていたら作り直させる）。
2. `assets/sigcmp/` に保存し、spec の `images` は3モデルとも同じキー名（`intro`・`law`・`world`）にする。
3. 4章（language）と6章（end）は、`art_intro.png` と `art_world.png` を使い回す。
