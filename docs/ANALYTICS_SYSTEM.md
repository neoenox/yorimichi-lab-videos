## 0. 結論

いまの分析で最も重要なのは「表示回数が付いているか」を「クリックされたか」より先に見ること。長尺は28日で198回・約3.5時間で、2026-11-01時点では15本中6本が0再生、公開から11日で0のものもあった。これはサムネイルやタイトルの良し悪しを測る以前の段階。Shortは1,200回前後の「床」に13本が並び、内容の差が数字に出ていない。

分析の順番はこれに固定する。

1. 届いているか（インプレッション）
2. クリックされたか（CTR）
3. 見続けられたか（維持率・平均視聴時間）
4. 登録・次の動画へ移ったか（転換率・導線）
5. 収益につながったか（視聴時間・広告）

## 2. 成功パターンの特定

実測から言えることだけを書く。相関は因果ではない。

### 2-1. 尺

| 尺 | 本数 | 再生（中央値） | 平均視聴率 |
|---|---:|---:|---:|
| 30〜45秒 | 29 | 715.0 | 60.9% |
| 46〜60秒 | 48 | 334.0 | 52.9% |
| 61〜75秒 | 34 | 216.0 | 46.0% |
| 76秒以上 | 16 | 724.0 | 54.7% |

公開からの日数は各群10〜14日で大きく差がなく、尺の効果と無関係とは言い切れない。30〜45秒を標準にするが、断定はしない。

### 2-2. テーマ

history（28本）は中央値622回・平均視聴率60.8%。news（24本）は163.5回・42.2%。ニュースは鮮度が落ちやすい。テーマ分類はタイトルのキーワード一致で、「other」が64本あるので、この表は粗い。

### 2-3. 繰り返し視聴

平均視聴率が100%を超えた13本は再生中央値918回、100%以下の114本は288回。上位は short_koku 123.1%、short_scurvy 143.6%、short_oke 114.8%。数字の比較・図解でリピートを誘う構成が再生に効いている。

### 2-4. 冒頭フック

| 型 | 例 | スワイプ率 | 継続率 |
|---|---|---:|---:|
| 旧型（問い＋答え先出し） | 玉川上水 | 73.5% | 26.5% |
| 旧型 | プラニマル | 71.8% | 28.2% |
| 新型（4〜6秒に数字） | 凌雲閣 | 90.0% | 10.0% |
| 下位の基準 | 厳島・うめきた | 81.2%／82.2% | 18.8%／17.8% |

新型は入口の離脱が明らかに悪い。凌雲閣は平均視聴割合53.3%と矛盾したシグナルも出たが、スワイプ率を最優先とし、判定は11/26まで保留する（[kpi_swipe_tracking.md](kpi_swipe_tracking.md)）。同じ型が5本たまるまで「勝ち」と呼ばない。

### 2-5. 投稿時刻

20:00が中央値569回、19:00が445.5回、17:00が338回、12:00が237回。ただし本数が2〜8本で、時刻の効果とは断定できない。

### 2-6. 導線

2026-11-01時点でShort再生15,173に対し長尺31、0.20%。Shortの流入元はショートフィード97〜100%で、検索は1.8%。関連動画の設定が13本中3本未設定で、Shortが配られる48時間のあいだ長尺への入口が空いていた。これが低転換の主因。

## 3. 低パフォーマンス動画の切り分け

数字の組み合わせで原因を分ける。同じ症状でも対処が違う。

| 観測 | 判断 | 最初に疑う場所 | 次の手 |
|---|---|---|---|
| インプレッションがほぼ0 | 配られていない | タイトル・サムネではなく配信面 | 投稿時刻、関連動画設定、再生リスト。長尺はまず導線 |
| インプレッションはあるがCTRが低い | 出口が弱い | サムネイルとタイトル | 数字＋結果型へ。同じ柱の上位と下位を比べる |
| CTRは普通だが継続率が低い | 冒頭で離脱 | 最初の1〜3秒 | フックの型。新型は使わない |
| 継続はするが平均視聴率が低い | 中盤で離脱 | 章の変わり目、画面の単調さ | 3分ごとに画面を変える。章頭で前章の結論を1文 |
| 平均視聴率が高いが登録が増えない | 次の行動が無い | 導線 | 関連動画、固定コメント、再生リスト、終了画面 |
| Shortは伸びているが長尺が0 | 移る道が無い | Short→長尺の入口 | 長尺19:00→関連動画19:30→Short20:00の順を守る |

低再生の下位20本は公開から11〜15日で1〜45回。内容の修正より、まずインプレッションが付いているかを確認する。

## 4. 週次レビュー（毎週月曜）

所要の目安30分。見る数字は7つだけ。

| 順 | 指標 | 見方 | 記録先 |
|---|---|---|---|
| 1 | 表示回数 | 動画別に前週比。0に近い本数を数える | `data/studio_notes.md` |
| 2 | CTR | 動画別。柱ごとに上位・下位を1本ずつ拾う | `docs/research/` |
| 3 | スワイプ率 | `python scripts/studio_swipe.py <ids>` | [kpi_swipe_tracking.md](kpi_swipe_tracking.md) |
| 4 | 平均視聴時間 | 長尺とShortを分ける。長尺は実時間で見る | `data/studio_notes.md` |
| 5 | 登録者増 | 1日3人を目標。増えた動画を特定する | API |
| 6 | 長尺再生÷Short再生 | 0.20%から1%へ動くか | API |
| 7 | 導線の設定漏れ | `scripts/check_slots.py` と関連動画の未設定数 | 台帳 |

週次の手順：

1. `python scripts/collect_stats.py` で再生・高評価・コメントを `data/channel_stats.jsonl` に追記。
2. `python scripts/yt_api.py stats` で公開日時と再生を確認。台帳の `publishAt` は実態より古いことがあるので、APIを正とする。
3. Studioから動画別のインプレッションとCTRを手で読み、CTRが下がっている本を特定。
4. 前週に公開した動画のうち、上位1本と下位1本を選び、[hook_patterns.md](hook_patterns.md) に1行ずつ足す。
5. 假説を1つだけ立てる。変えるのは1つの変数だけ。
6. 週の題材採点に反映する。活用7割・探索3割（[PRODUCTION_CYCLE.md](PRODUCTION_CYCLE.md)）。

## 5. 月次レビュー（毎月第1月曜）

所要の目安1時間。週次は「今週の異常」を見つける場、月次は「型の勝敗」を決める場。

| 項目 | 中身 | 判定 |
|---|---|---|
| 柱ごとの1本あたり再生 | 合戦の地理／江戸の暮らし／東京の低地 | 配分を変える。柱1が3か月動かなければ柱2へ主軸移動 |
| 尺別の中央値 | 30〜45／46〜60／61〜75／76秒以上 | 標準尺の見直し。同じ時期で比べる |
| テーマ別の中央値 | history／news／calendar／other | ニュースは週1本までという上限を守れているか |
| フック別のスワイプ率 | 旧型／新型 | 同じ型が5本たまったら判定。揃わなければ保留 |
| タイトル型別CTR | 数字＋結果／「〜で確かめる」 | 3本以上たまってから比較 |
| 導線の転換 | 長尺再生÷Short再生 | 1%に届くか |
| 収益 | 視聴時間と広告収入 | 本則通过后のみ。未収益化なら「該当なし」と書く |
| 権利と審査 | 違反警告、BGM表記、地理院の扱い | 未確認が残っていれば申請前に潰す |

月次の成果物は `docs/research/<年月>_review.md` に1枚で残す。採用した施策と不採用の理由を分けて書く。AIの指摘は原文と実フレームで照合してから採否を決める。

## 6. 維持率グラフの読み方（未取得を先に取得する）

Studioの動画分析 →「視聴者の維持」から、時間軸ごとの残留率を読む。いま取っていないので、まず直近の長尺3本とShort3本を記録する。

見るのは3点だけ。

- 最初の数秒の急落：冒頭フックの問題。スワイプ率と合わせて読む。
- 25%地点：目標50%以上。ここが低いと平均視聴時間が伸びない。
- 章の変わり目の段差：図やカードの切り替えで離脱が止まるか。

グラフは1本だけ見ても判断しない。同じ柱・同じ尺の3本を並べ、共通の落ちる地点を探す。

## 7. 登録者への転換率

いま計算していない。分母と分子は揃っているので、週次で次を出す。

```
転換率 = その動画で増えた登録者数 ÷ その動画の再生数
```

2026-11-01時点の観測では「登録者はShort 1本につき+1」、Short 1,236回で+1なら約0.08%。ただしこれはある1本の観測で、集計期間も不明。週次で全動画に広げてから傾向を言う。

転換率が低いときは、再生数を増やすより先に導線を疑う。関連動画、固定コメント、再生リスト、終了画面の順に確認する（[CHANNEL_STRATEGY_20261124.md](CHANNEL_STRATEGY_20261124.md) 7）。

## 8. トラフィックソース

取得したら、検索型と発見型を分ける。

- ショートフィードが97〜100%の動画は発見型。登録への転換が弱い。
- 検索からの流入がある動画は、タイトルと概要欄の年号・地名・数字が効いている。柱2・柱3はこちらを狙う。
- 関連動画からの流入が増えたら、再生リストと導線の設定が効いている。長尺再生÷Short再生と一緒に見る。

全動画の内訳は未取得。最初の1週間でStudioから取る。

## 9. 分析のルール

1. 同じ時期・同じ条件で比べる。伸びた時期を混ぜると判断を誤る（2026-11-14に地図型を「不調」と判断し、翌日訂正した例がある）。
2. 1本200回ではノイズが大きい。同じ型が3本（CTRは5本）たまるまで判定しない。
3. 相関は因果ではない。尺・題材・時刻は互いに効くので、1変数だけ変えるテストで確かめる。
4. 未取得を0と書かない。「未取得」と書いてから取得する。
5. 技術検証（デコード・音量）と視聴品質は別の結果として記録する。
6. 2026-11-16以降の数字は集計仕様が違う。前後比較には注記を付ける。
