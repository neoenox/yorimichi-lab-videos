# Muse.ai 動画生成 試用プロンプト（舌の味覚マップ）

作成日：2026-11-23

目的：muse.ai で動画生成が使えるか試す。直近の完成ショーツ `shorts/tongue_taste_map/result.json` の6シーンを、そのまま6クリップとして投げる想定のプロンプト。実験用で、既存の動画・台本・素材は変更しない。

## 共通の前提（全クリップに共通して付ける）

```
素材はすべて模式図・イラストとして作成する。実写や実物の舌として描写しない。文字は日本語で、太字の短い文言のみ。背景は淡いベージュ、線は落ち着いた紺色。カメラは固定、ズームやドリーは使わない。音声・ナレーション・BGMは入れない。著作物のキャラクター、ロゴ、実在人物の肖像は使わない。
```

## クリップ1（0–3秒／フック）

```
舌の模式図を正面から見せる。舌の先端に甘味、奥に苦味、横に塩味と酸味を四つの区域にはっきり色分けして配置する。教科書の図のような四是に分けた地図。画面上部に「舌の先は甘味、奥は苦味。ほんと？」と大きな文字。区域の色が順に薄く光ってから一定になる。カメラ固定。模式図と明記する小さな文字を右下に置く。
```

## クリップ2（3–8秒／結論の提示）

```
クリップ1と同じ舌の模式図。四つの区域の色分けと境界線が消え、甘味・苦味・塩味・酸味・うま味の記号が舌の縁と上面の広い範囲に均等に並ぶ。境界線が右から左へ消えていく動き。画面上部に「地図は誤り。専用区域はない」と文字。カメラ固定。模式図と明記する小さな文字を右下に置く。
```

## クリップ3（8–15秒／1901年の測定）

```
1901年の感度グラフを模式図で再現する。横軸に舌の位置、縦軸に感度を置き、甘味と苦味の曲線がわずかに起伏するだけであることを示す。舌の模式図に薄い色を全体へ広げ、差の小ささを波の高さで表現する。グラフ上部に「ヘーニッヒ 1901」と文字。カメラ固定。数値は書かない。模式図と明記する小さな文字を右下に置く。
```

## クリップ4（15–23秒／誇張されて地図になった）

```
模式図。左に1901年の小さな起伏グラフ、右に甘味・苦味・塩味・酸味へ四等分した舌の地図を並べる。左から右へ向かう矢印が中央に現れ、グラフの小さな波が右のはっきりした色分けへ変わっていく。矢印の下に「1912 → 1942」と小さく文字。画面上部に「小さな差が誇張された」と文字。カメラ固定。模式図と明記する小さな文字を右下に置く。
```

## クリップ5（23–31秒／差はゼロではない）

```
舌の模式図に薄い濃淡を重ねる。五つの味を舌全体で感じられるよう記号を広く保ちながら、場所によるわずかな感度差を色の濃さで示す。専用区域を赤字のバツで一つ消す。画面上部に「差はゼロではない。でも専用区域はない」と文字。カメラ固定。模式図と明記する小さな文字を右下に置く。
```

## クリップ6（31–39秒／まとめ）

```
模式図。左に四色に分けた古い舌の地図、右に五つの味が舌全体へ広がる現在の模式図を左右に並べる。左の下に「誤り」、右の下に「現在の理解」とラベルを付ける。最後に画面中央へ「地図ではない。少しの差があるだけ」と結論の一文が現れる。カメラ固定。模式図と明記する小さな文字を右下に置く。
```

## 注意

- 6クリップを一気に投げる前に、1クリップだけ出して画風と文章の出方を確認する。
- 生成動画はイメージであることを、実際に使うなら概要欄などに明記する。
- 史実の監修は元の `result.json` の claims を根拠にする。生成映像の文字や図を根拠にしない。
- 音声・字幕同期・連続視聴は、実際に生成されたファイルを確認するまで評価しない。
