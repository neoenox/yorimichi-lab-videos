## 4. 採用・不採用のまとめ

両AIの指摘のうち、気象庁FAQ原文と照合して**採用**したのは次の3点（重複を統合）。いずれも原文に存在する表現へ戻す／原文に無い限定を外すだけであり、新しい事実・数字・数式・断定は加えない。

1. シーン1（および hook）の「違うのは、光が大気を通る距離**だけ**です」から「だけ」を外す／弱める（G2・C2）。根拠は原文「大気を通過する距離が長くなり」。
2. シーン6 テロップ「昼は短く、夕は長く」を、何が短い／長いか分かる表現（例：「昼は距離が短く、夕方は長い」）にする（G3・C6）。根拠は原文「通過する距離が長くなり」。
3. シーン6 ナレーション「短い光は散乱され」を「波長の短い光は散乱され」など原文の用語に統一する（C5）。根拠は原文「波長の短い光」。

**不採用**の主な理由は、(a) 気象庁原文に完全一致する表現を別の物理解釈で修正しようとするもの（C1）、(b) 原文に無い要因を追加するもの（C3、C2のちり・水滴の具体化）、(c) `end: true` の ending 指定を記載漏れと誤認したもの（G1・C7）、(d) すでに原文どおり「多く」と書いているもの（C4）、(e) 台本レビューの範囲外（出典表記 G4、音声速度 G5、定型句 C8、レイアウト G6）。

**オーナー指示「冒頭の結論フリップは不要」**: 今回も両AIとも冒頭で結論を言うべきとは要求していない。既に caption「なぜ夕焼けは赤い？」／hook 疑問形で反映済み。もし要求が出てもオーナー指示を優先して不採用にする。
