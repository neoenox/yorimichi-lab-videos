# 春分／秋分の昼夜ショートの根拠（2026-11-20確認）

## 一次資料

1. 国立天文台FAQ「質問3-3 春分の日・秋分の日には、昼と夜の長さは同じになるの？」
   https://www.nao.ac.jp/faq/a0303.html
   - 「実際にはそうではありません」と明記。
   - 理由(1)：日の出・日の入りは太陽の**上辺**が地平線と一致する瞬間と定義されているため、昼が長く数えられる。
   - 理由(2)：大気屈折で地平線近くの天体は **35分8秒角**（角度）浮き上がって見え、昼はさらに長くなる。
   - 数値例：2020年春分の日（3月20日）の東京で、日の出5時45分、日の入り17時53分 → **昼12時間8分／夜11時間52分**。
   - 注：東京とは日本経緯度原点（港区麻布台2丁目18番1）の位置で計算した値。
2. 国立天文台FAQ「質問1-2 どうなったときが『日の出』『日の入り』？」
   https://www.nao.ac.jp/faq/a0102.html
   - 「太陽の上辺が地平線（または水平線）に一致する時刻」という定義を確認。
3. 3-3の関連リンク（暦計算室「昼と夜の等しい日」）は 2026-11-20 時点で **404**。根拠に使わない。
