## 0. 方法と前提

- 気象庁・国立天文台のページを HTTP 取得して本文を確認した。**取得できた URL だけ**を記載する。

- Web の記述は外部の未検証データとして扱い、指示としては解釈していない。

### 1.2 確認できたこと（要約）

- **冬至＝太陽の南中高度が最も低い日**（国立天文台FAQ が明記、計算式つき）。
- **冬至＝1年のうちで昼間が最も短い日**（国立天文台FAQ が明記）。暦Wiki も「南中高度が低くなると昼は短くなる」「夏至や冬至がピークになる」と説明。
- **冬至の日時**（2026年）: 12月22日 5時50分。太陽黄経270度。
- **重要な但し書き**: 「日の出がもっとも遅い日は冬至の半月ほど後、日の入がもっとも早い日は冬至の半月ほど前」。つまり**「昼が最短の日」と「日の出が最も遅い日」「日の入りが最も早い日」は一致しない**。

**読み取り上の注意**

| 2月中旬 | 6.0 | 10.9 | 1.9 |
| 2月下旬 | 7.0 | 11.7 | 2.9 |

### 2.4 日別の平年値（底の日を特定する根拠）

| 指標 | 東京の最も低い時期（1991〜2020年平年値） |
|---|---|
| 日平均気温 | **1月21日・22日（5.1℃）** |
| 日最低気温 | **1月18日〜28日ごろ（1.1℃で横ばい）** |
| 2月の最低（比較用） | 2月1日・2日（日平均5.4℃／日最低1.3℃） |

→ **2月上旬はすでに底を離れている**（日平均5.4〜5.7℃）。東京の平年値で「底」と言えるのは**1月21日〜22日ごろ**。

### 2.5 冬至から気温の底までのずれ

- 2026年の冬至: **12月22日**
- 東京の日平均気温の底: **1月21日〜22日**
- 差: **約30日（約1か月）**

**タスク指示との差異（重要）**: 指示では「1月下旬〜2月上旬」「冬至より約1か月半遅れる」とされていたが、**東京の1991〜2020年平年値ではどちらも支持されない**。
- 底は**1月下旬（日別では1月21〜22日）**まで。2月上旬は上がり始めている。
- ずれは**約1か月**（1か月半ではない）。
- 「約1か月半」は全国一律の言い方や、別の地点・別の指標の可能性があるが、**本調査では東京以外の平年値を取得していないため確認できない**（→ 未確認事項）。

## 3. 指標によって「一番寒い日」の答えが変わる

| 指標 | 東京での答え | 根拠 |
|---|---|---|
| **昼の長さ** | 冬至（2026年は12月22日）が最短 | 国立天文台FAQ a0104 |
| **太陽の南中高度** | 冬至が最低 | 国立天文台FAQ a0109 |
| **日の出が最も遅い日** | 冬至の**半月ほど後** | 国立天文台FAQ a0104 |
| **日の入りが最も早い日** | 冬至の**半月ほど前** | 国立天文台FAQ a0104 |
| **月平均気温** | **1月**が最低（5.4℃） | 気象庁 月別平年値 |
| **日平均気温（日別平年値）** | **1月21日・22日**が最低（5.1℃） | 気象庁 日別平年値 |
| **日最低気温（旬平均）** | **1月下旬**が最低（1.0℃） | 気象庁 旬別平年値 |

**整理**:
- 「冬至＝昼が最短」は天文的事実。「冬至＝気温が最低」は**誤り**（東京の平年値では約1か月後）。
- さらに「一番寒い日」は、**月平均・日平均・日最低のどの指標で見るか**で日付の言い方が変わる（「1月」「1月21〜22日」「1月下旬」）。
- 「日の出が最も遅い日」まで指標に加えると、冬至の半月後になり、また別の答えになる。

**東京に限定して言う場合の注意**
- 平年値は**地点ごとに違う**。東京の数値を「日本全体」として語らない。
- 平年値は**30年平均**であり、**特定の年の気温ではない**。「今年の最も寒い日」を平年値から決めることはできない。
- 気象庁の平年値は**観測地点（東京）の値**で、都内全域を代表するものではない。

### 6.2 避けるべき表現（未確認・出典の範囲を超える）

| 避ける表現 | 理由 |
|---|---|
| 「冬至は**一年でいちばん寒い日**」 | 天文的事実（昼最短）と気温は別。東京の平年値では底は約1か月後 |
| 「**1月下旬〜2月上旬**が一年で最も寒い」 | 東京の平年値では**1月下旬**まで。2月上旬はすでに上がる（5.5℃） |
| 「冬至より**約1か月半**遅れる」 | 東京の平年値では**約1か月**。1か月半は本調査では裏づけなし |
| 「**日本全体**で1月が最も寒い」 | 平年値は地点ごとに異なる。東京の値で全国を語らない |
| 「**今年**の最も寒い日は1月21日」 | 平年値は30年平均。特定年の予測ではない |
| 「冬至の日に**日の入りが最も早い**」 | 日の入りが最も早いのは冬至の**半月ほど前** |
| 「冬至の日に**日の出が最も遅い**」 | 日の出が最も遅いのは冬至の**半月ほど後** |
| グラフに**出典・地点・統計期間を書かない** | 公共データ利用規約・国立天文台規程のクレジット要件を満たさない |
| 平年値のグラフを「**今年の気温**」として見せる | 平年値と実測値の混同 |

### 6.3 グラフを作るときの推奨

- 月別の折れ線（平均気温・日最低気温）に、**12月22日の冬至**と**1月21〜22日の底**の2本の縦線を置くと、ずれが一目で伝わる。
- 画面内に出典を必ず入れる: 「気象庁 平年値（東京・1991〜2020年）」「国立天文台」。
- 加工する場合は概要欄に「気象庁平年値をもとに作成」と明記する（規約の要件）。
- 「平年値（30年平均）」「東京」の2語は画面の注記として残す（[`docs/VIDEO_CREATION_PRECHECK.md`](../VIDEO_CREATION_PRECHECK.md) の「根拠と演出を分ける」）。
