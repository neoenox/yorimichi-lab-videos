# 月食Short の根拠確認（2026-11-26）

題材：満月のたびに月食が起きる？

## 一次資料

### 国立天文台 暦Wiki「月食／なぜ毎月(望)に月食がおこらないのですか」
https://eco.mtk.nao.ac.jp/koyomi/wiki/B7EEBFA92FBEF2B7EF.html
- EUC-JP で web_fetch すると文字化けする。Python の `urllib` で取得して `decode('euc_jp')` して本文を読んだ。
- 原文：「月の公転軌道面は地球の公転軌道面である黄道面に対して5.1°程度傾いています。」
- 原文：「しかし、実際にはこの傾きのために、軌道の交点付近で満月(望)となるときにしか月食は起こりません。」
- 原文：「交点付近に来るのは約半年に1回ですから、月食も約半年に1回程度ということになります。」
- 原文：「地球(太陽)と月の動きは連動しておりませんので、必ずしも毎回交点ぴったりで満月(望)となるわけではありません。」

## 台本の方針

- 答えを先に出す：「なりません。満月と交点付近、両方が必要です」。
- 数字は原文どおり「5.1°」「約半年に1回」。「年数回」のような曖昧な丸めは使わない。
- 用語：白道（月の公転軌道面）、黄道（地球の公転軌道面）、交点。読み辞書に登録して kana で確認する。
- 断定を避ける：「満月＝月食」と言い切らず、交点付近という条件を必ず併記する。
- 国立天文台の図・画像は転載せず、自作の模式図にし「模式図」と明記する。
