## 3. 未確認（確認していないこと）

1. **朱引線・墨線の実視認**。公文書館の高精細画像は取得可能（HTTP 200・約57MB／約86MB）だが、**画像を保存して開く行為は今回の制約（書き込みは成果物のみ）で行っていない**。したがって「画像上で朱線が読めるか」「2コマのどちらが本図か」「縮尺・方位」は未確認。**推測**: 高精細 JPEG が約57〜86MB あるため、朱線の判読に足る解像度はある可能性が高いが、確認していない。
2. **江戸切絵図に朱引線が描かれているか**。NDL・東京都立図書館の江戸切絵図デジタル資料は確認したが、**画像を見ていないため、朱引線の有無は資料ごとに未確認**。切絵図は民間出版の案内図であり、幕府の朱引図とは性格が違う（**推測**。出典未確認）。
3. **作成年・作図者**。館の資料詳細には作成年の記載が無い。1818年（文政元年）とするのは Wikipedia（二次）の記述のみ。**公文書館側の資料で確認していない**。
4. **版の違い**。「幕府の朱引図は複数版がある」という前提を、**確認できた資料では裏付けられなかった**。別系統の「[江戸朱引圖]」（写本・彩色、NDL サーチで書誌のみ）の存在は確認したが、系統関係・作成年は未確認。復刻版（2015）の解題に版の整理がある可能性が高いが、**紙媒体で未読**。
5. **デジタルアーカイブ画像の二次利用条件**（動画への収録、概要欄のクレジット文言、申請の要否）。案内ページの本文が取得できず、**「公開されている＝自由に使える」とは言えない**。
6. **港区史の解説本文**（「江戸の範囲と港区域」）。テキストページの存在は確認したが、本文はビューア画像側にあり未読。検索エンジンのスニペットに「現在のJR山手線と都営大江戸線環状部分の範囲をイメージするとおおむね近い」「港区域は全て朱引内（御府内）・墨引内に位置する」と見えるが、**スニペットは未検証データなので根拠にしない**。
7. **現代地図への重ね合わせの妥当性**。江戸絵図は方位・縮尺が一様でないため、現代地図（地理院地図等）への幾何補正には基準点の選定と誤差の評価が要る。**この検証は行っていない**（先行事例も未調査）。
8. **「朱引内に人が住んでいなかった」わけではないという点の裏付け**。朱引内には町人地・武家地・寺社地・田畑が混在し、人口分布は一様でない——という説明は、**取得できた資料では確認できていない**（§5-2）。

## 4. 追加で必要な資料・作業

1. **公文書館デジタルアーカイブの利用条件**（最優先）。`0304digital_archives` の本文を人が読む、または館へ問い合わせる。決めることは、①動画への収録可否 ②必要なクレジット文言 ③申請の要否。
2. **「旧江戸朱引内図 復刻と解題」（2015）の解題本文**。作成年・版・朱引と墨引の説明がまとまっている可能性が高い（**推測**）。図書館で現物確認（ISBN 978-4-86569-166-5）。あわせて『研究紀要』第4号「江戸の範囲」PDF（45-48頁）も読む。
3. **朱引線の可読性の実確認**。高精細画像を取得し、①朱線が連続して追えるか ②墨線と区別できるか ③地名・方位・縮尺の手がかりがあるか、を実画像で確認する（§3-1）。
4. **幾何補正の方法**。現代地図に重ねるなら、基準点（江戸城・日本橋・主要寺社など）の選定と、誤差を画面にどう断るかの方針を決める。先行事例（他館・研究）の調査は未実施。
5. **「朱引＝御府内の範囲」であり「人が住んでいた範囲」ではないことを述べた公的解説**。公文書館の「江戸の範囲」ページ本文、または港区史の該当箇所を人が読んで確認する。
6. （代替案）**一次画像を使わない模式図ルート**にする場合に必要な資料は、上記2の解題と、範囲の概略（東西南北の端＝平井・亀戸／代々木・角筈／品川／千住・板橋。これは Wikipedia の記述なので要裏取り）だけ。**模式図と明記すれば画像の利用条件問題は回避できる**が、史実の裏取りは別途必要。

## 5. 制作上の注意（今回の調査で見つかったこと）

### 5-1. 「朱引＝町奉行支配の範囲」は、確認できた整理と食い違う

- 取得できた二次資料（Wikipedia「朱引」）の整理は、**朱引＝幕府が定めた江戸の範囲（＝御府内）**、**墨引＝町奉行所支配の範囲**で、墨引は朱引より内側（目黒付近で朱引の外に突出する例外あり）。
- したがって台本で「朱引は町奉行が支配した範囲」と言い切ると、**資料の整理とずれる**おそれがある。言うなら「幕府が定めた江戸の範囲（御府内）。その内側に、町奉行支配を示す墨引が別に引かれていた」と区別する。
- ただしこの整理は Wikipedia（二次）に依拠している。**公文書館の解説で裏取りするまで断定しない**（§4-5）。

### 5-2. 「人が住んでいた範囲」という言い方

- 「朱引線＝人が住んでいた範囲」とすると誤解を招く。朱引は**行政上の範囲**で、内側の土地利用（町人地・武家地・寺社地・田畑）や人口密度は別の話。
- この点を**直接裏付ける解説文は、取得できた資料では確認できていない**（§3-8）。台本では「幕府が定めた範囲」と言い、「人が住んでいた範囲」とは言わないのが安全。
- 地図上で「朱引線の内／外」を示すときも、**人口や市街地の連続とは別の線**であることを画面か概要欄で一度断る（`docs/VIDEO_CREATION_PRECHECK.md`「根拠と演出を分ける」）。
