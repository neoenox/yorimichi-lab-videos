# 夕焼けShort v2 の視聴確認（2026-11-26、lead）

`out/short_solo_sunset_v2.mp4` に対する確認。担当 QA が成果物を出さずに終了したため、lead が実行して記録した。builder の技術検証（ffprobe・全デコード・LUFS・字幕時刻・代表フレーム目視）とは別に、連続再生と無音の観点で確認した。

## 確認結果

### 1. 連続再生（黒フレーム）

```
ffmpeg -hide_banner -i out/short_solo_sunset_v2.mp4 -vf blackdetect=d=0.1:pix_th=0.10 -an -f null -
```

→ 黒フレーム検出なし（0.1秒以上の黒画面は無い）。(full 早送り再生は ffmpeg のデコードで代替)

### 2. 音声（silencedetect）

```
ffmpeg -hide_banner -i out/short_solo_sunset_v2.mp4 -af silencedetect=noise=-35dB:d=0.3 -f null -
```

無音区間は次の7箇所。

| 開始 | 終了 | 長さ |
| --- | --- | --- |
| 5.48 | 6.11 | 0.62秒 |
| 10.61 | 11.26 | 0.65秒 |
| 17.72 | 18.34 | 0.62秒 |
| 22.96 | 23.57 | 0.61秒 |
| 31.14 | 31.75 | 0.60秒 |
| 37.50 | 38.11 | 0.61秒 |
| 44.36 | 45.49 | 1.13秒 |

文と文の切れ目に約0.6秒の間があり、末尾に1.13秒。不自然な長い無音は無い。builder の LUFS -15.3 / TP -1.5 dBTP と合わせ、音量面の異常は見当たらない。

### 3. 字幕同期

builder が代表フレームで確認済み。SRT `out/short_solo_sunset_v2_subtitles.srt` は 0.000〜44.543秒の18ブロックで、修正台本の文言を反映している。mp4 内に字幕トラックは無く、焼き込み字幕。

### 4. 可読性

builder の代表フレーム目視で、タイトル・大見出し・図・字幕・出典ラベルに重なり・はみ出しなし。末尾38〜45秒の結論カードと終了カードは `ytcore/make_short2.py` の nolong 分岐による設計どおり。スマホ実機はオーナー指示でスキップ。

## 未確認の範囲

- 全編の実聴（音切れ・ノイズ・BGMバランス）。この環境では音を聴けないため、silencedetect と数値で代替した。
- スマホ実機での可読性・UI被り。
- 動画レビューが指摘した「むらさき／紫」の表記揺れ、出典バッジの視認性、下部字幕の UI被りリスク。
- **投稿可の判断**。生成・デコード・blackdetect・silencedetect の結果だけでは投稿可と宣言しない。
