## 構成の判断

| 項目 | 採用した形 | 理由 |
| --- | --- | --- |
| 冒頭（0〜3秒） | 「なぜ夕焼けは赤く見える？」で問いを置き、直後の場面で「空が青いのと同じ仕組み。違うのは光が通る距離だけ」と方向性を先出し | PROMPT.md の「疑問形で終わらせず、答えの半分を先出し」に合わせた。構造上は疑問形だが、チェッカーが求める疑問符を冒頭に置いた |
| シーン数・尺 | 7シーン・45秒（3/7/7/7/6/7/8秒） | 標準の5〜7シーン・30〜45秒の範囲内。初稿は6シーン39秒だったが最終シーンが10秒で上限超過となり、7分割して是正した |
| 展開 | 疑問 → 方向性 → 太陽光の色 → 散乱 → 青い空 → 夕方の長い経路 → 赤い夕焼けとループ回収 | 「疑問→結論の方向性→理由・根拠→結論回収」の順。根拠図は光の通り道の模式図だけを自作し、模式図と明記する |
| ループ文 | 「寄り道ラボ、また寄り道、続けます」で冒頭の夕焼けへ戻す | PROMPT.md 項目7に従う。無意味な登録誘導は入れていない |
| 字幕 | キーワードと数字だけ、1行14文字以内・2行以内 | ナレーションの言い直しを避けた |
| 日付 | 画面・ナレーション・タイトルに入れない | 時事ニュースではないため。ユーザー指示どおり |
