## 検索・判定の方法（再現用）

1. 検索 URL は `https://www.youtube.com/results?search_query=<URLエンコードしたクエリ>&sp=EgIYAQ%253D%253D` を開いた。
2. **この `sp` 付き URL では、画面のチップが「すべて」選択のままで Shorts 絞り込みが効かなかった**（結果に通常動画 2:56 / 3:52 などが混在）。
   そこで各クエリで検索結果上部の **「ショート」チップをクリック**し、Shorts だけのグリッドに切り替えてから、表示順に上から記録した。

   **本編を開いて視聴した動画は 0 本**（§4 に限界を明記）。
4. 化粧品・健康食品・健康器具・医薬品、金融・投資は対象外（睡眠 改善のみ、除外判断の材料として計測）。
