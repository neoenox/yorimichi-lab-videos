### 1.2 設問（原文）

報告書 p.82（PDF 内では通し 82 ページ）より:

> 24．慣用句等の意味
> 問24〔回答票〕あなたは，ここに挙げた（１）から（４）の言葉の意味は，それぞれ（ア）と（イ）のどちらだと思いますか。
> （３）小春日和　〔例文：今日は小春日和です。〕

選択肢（同ページのグラフ）:
- （ア）**初冬の頃の，穏やかで暖かな天気**
- （イ）**春先の頃の，穏やかで暖かな天気**
- （ウ）（ア）と（イ）の両方
- （エ）（ア）や（イ）とは全く別の意味
- （オ）分からない

**注意**: 設問の例文「今日は小春日和です。」には季節を示す手がかりがない。回答者は語そのものの意味の認識で答えた、という形式である（設問の作り方の評価は本調査の範囲外）。

### 1.3 結果（n=1,942）

報告書 p.90「図15」および p.86 の本文、概要版 p.19 の3か所で**同一の数値**を確認した。

| 選択肢 | 割合 |
|---|---|
| （ア）初冬の頃の、穏やかで暖かな天気（本来の意味） | **51.7%** |
| （イ）春先の頃の、穏やかで暖かな天気 | **41.7%** |
| （ウ）（ア）と（イ）の両方 | 3.1% |
| （エ）（ア）や（イ）とは全く別の意味 | 1.8% |
| （オ）分からない | 1.8% |

報告書 p.86 の本文（原文）:

> 本来の意味である「初冬の頃の，穏やかで暖かな天気」と回答した人が51.7％で，「春先の頃の，穏やかで暖かな天気」（41.7％）と回答した人の割合を10 ポイント上回っている。

年齢別（概要版 p.19）:
> 「春先の頃の，穏やかで暖かな天気」の割合は，16～19 歳で66.1％，20代で54.5％と他の年代より高く５割を超えている。

**「約5割／約4割」で足りるか**: 丸め自体は誤りではない（51.7→約5割、41.7→約4割）。ただし原典は**小数第1位まで公表されている**ので、台本・説明欄では「51.7% / 41.7%」を出し、必要なら「約5割 / 約4割」を併記するのが安全。**「10ポイント差」という原典の表現も使える**（丸めた「5割と4割」だと差が伝わりにくい）。

### 2.2 確認できたこと

- 「小春」は**陰暦（旧暦）10月の異称**である（デジタル大辞泉・精選版 日本国語大辞典・学研全訳古語辞典で一致）。
- 新暦では**おおよそ11月から12月上旬**にあたる（日本大百科全書・ブリタニカ・世界大百科事典旧版で一致）。「ほぼ11月」（百科事典マイペディア）とも。
- 別称に**「小六月（ころくがつ）」**がある（日本大百科全書・百科事典マイペディア）。
- 語の由来について: 学研全訳古語辞典は「**漢語「小春（せうしゆん）」の訓読**」と明記。精選版 日本国語大辞典は「小春（しょうしゅん）」項の参考文献に〔荊楚歳時記〕を挙げる。

### 2.3 「漢籍由来」の確認範囲

- **確認できた**: 語が漢語（中国語）に由来し、古語辞典が「漢語『小春』の訓読」と説明していること。日本の辞書が中国の歳時記〔荊楚歳時記〕を関連文献として挙げていること。
- **未確認**: 「小春」が**特定の漢籍のどの句**に由来するか。原典（荊楚歳時記の本文）は今回確認していない。Wikipedia は「漢籍で旧暦10月の異称」と書くが、その典拠（気象科学事典）は現物を確認していない。
- → 番組では「**漢語に由来する語**」までにするのが安全。「◯◯（書名）が出典」と書くと未確認の断定になる。

## 4. 「誤用」という説明はどこから来るか（切り分け）

**結論: 文化庁調査からは「誤用だ」とは言えない。調査は意味の認識分布を聞いただけである。**

| 言説 | 出所 | 確認結果 |
|---|---|---|
| 「初冬の頃の、穏やかで暖かな天気」が本来の意味 | 文化庁報告書 p.86 | **確認済み**。報告書は「本来の意味である」と書く |
| 春先の意味は「本来の意味ではない」 | デジタル大辞泉の補説（コトバンク） | **確認済み**（辞書の記述） |
| 「誤用」「間違い」 | — | **文化庁調査には無い**。PDF 全文を検索して「誤用」「誤解」は小春日和の記述に出現しない（「間違えて使っている」は別設問の言葉遣いに関する選択肢） |
| 「しばしば春先の暖かい日と誤解される」 | 日本語版 Wikipedia（出典は NHK ハンドブック・光村図書） | Wikipedia の表現。**この2冊／ページの現物は未確認** |

**使い分けの指針**:
- 文化庁調査を根拠にできるのは「**本来の意味（初冬）と答えた人が51.7%、春先と答えた人が41.7%**」という事実まで。
- 「誤用」と言うなら、それは**規範的な評価**であり、文化庁調査ではなく辞書の「本来の意味ではない」という記述に由来する、と分けて示す。
- さらに、**41.7% が春先の意味で使うと答えている**という事実は「春先の意味は誤り」と言い切ることと緊張する。番組で扱うなら「多数派は初冬だが、4割は春先の意味で使っている」という**分布として見せる**ほうが正確。

## 5. 現状の根拠（Wikipedia）との差分

| URL | 何が確認できたか |

- Wikipedia の「誤解される」は百科事典の記述であり、**動画の断定根拠にはしない**。
