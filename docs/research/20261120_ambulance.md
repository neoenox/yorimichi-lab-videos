# 救急車の軽症ショートの調査・制作（2026-11-20）

## 題材の経緯

Ask StudioにShorts案を聞き、3案（救急車の軽症／賞味期限／森林資源）から、既存動画と重複がなく一次統計で検証できる**救急車の軽症半数**を選択。

## 一次資料（2026-11-20本文確認）

- 総務省消防庁『令和7年版 消防白書』「1．救急業務の実施状況」
  https://www.fdma.go.jp/publication/hakusho/r7/chapter2/section5/69369.html
  - 「令和6年中の救急自動車による搬送人員676万9,172人のうち、46.9％が入院加療を必要としない軽症（外来診療）傷病者及びその他（医師の診断がないもの等）」
- 同 資料2-5-5「救急自動車による事故種別傷病程度別搬送人員の状況」
  https://www.fdma.go.jp/publication/hakusho/r7/document/69514.html
  - 軽症（外来診療）＝「傷病程度が入院加療を必要としないもの」
  - その他＝「医師の診断がないもの及び傷病程度が判明しないもの、その他の場所へ搬送したもの」

## 答え

搬送者の46.9%は「入院がいらない軽症など」。**軽症は「入院加療が不要」という定義であって、緊急でない・不要な利用を意味しない**。46.9%は軽症とその他の合算で、利用動機は統計から分からない。
