# 息が白くなる現象の根拠確認（2026-11-25）

題材：冬に息が白くなるのは気温の低さだけが原因じゃない。

## 一次資料

### 気象庁「はれるんランド」
https://www.jma.go.jp/jma/kids/kids/faq/a2_01.html
- ひこうき雲について「上空の温度の低く湿度の高い空気中にジェット機などの温度の高いはい気ガスが放出されたときに、排気ガス中の水蒸気などが小さな水てきとなって雲ができる現象で、冬の寒い日に人間がはく息が白く見えるのと同じことです」と明記。
- 「当然、上空の温度や湿度、ジェット機のはい気ガスの温度などにより、ひこうき雲ができるときとできないときがあります」とあり、温度だけでなく湿度も条件であることが分かる。

### 豊川市清掃工場の白煙について（自治体）
https://warp.ndl.go.jp/info:ndljp/pid/10299136/www.city.toyokawa.lg.jp/shisetsu/sonota/seisokojo/hakuen.html
- 「白煙とは、ごみや排ガス処理に含まれる水分から発生する排ガスの水蒸気が冷えて水滴に変わり（結露）、真っ白な煙のように見える状態」と定義。
- 「気温が低い冬場の早朝、特に湿度の高い雨天時に目立ちます。吐く息が白くなる寒い季節とほぼ同じ」と明記。湿度が高いと白く見えやすいことが分かる。

### 高校生のための科学（JST、PDF）
https://koushien.jst.go.jp/koushien/pastexam/2016/files/1-1.pdf
- やかんの湯気を題材に、水蒸気圧と飽和水蒸気圧の関係（温度だけでなく水蒸気量も関係）を解説。「温度だけを考えましたけれども…空気とその中に含まれる水蒸気も混ざる」とある。

### JAL 天気情報（参考・二次に近い）
http://weather.jal.co.jp/seasonal/12/seasonal_12f.html
- 口の中の温度は約36℃。吐く息が白くなりはじめるのは気温13℃以下が目安。雨の日は湿度が高く、気温が13℃より下がらなくても白く見えやすい。口をとがらせず大きく開けるほど白い。

## 台本の方針

- 答えを先に出す：「寒さだけじゃない。湿度も関係しています」。
- 仕組み：体温約36℃の息に含まれる水蒸気が、冷たい外気に触れて水滴になる（結露）。目に見えるのは水滴。
- 温度だけではない根拠：気象庁のひこうき雲の説明が温度と湿度の両方に触れている。豊川市の説明も湿度の高い雨天時に目立つと明記。
- 断定を避ける：「13℃以下が目安」は JAL の説明で、気象庁の値ではない。台本では「目安として言われる」と留保する。
- 数字：36℃、13℃、湿度。画面に出す数字は公的資料の記述どおりにする。
