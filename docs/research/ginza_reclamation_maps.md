# 銀座周辺の埋め立て前後を比較する地図資料

確認日：2026-11-04  
対象：銀座・江戸前島・日比谷入江周辺。動画ファイルは変更していない。

## 結論

銀座周辺を含む江戸初期の地図画像は、国立国会図書館デジタルコレクションから高解像度で取得でき、確認した3資料はいずれもNDLの権利情報がPDM（パブリックドメイン・マーク）です。出典を画面または概要欄に示して利用できる候補です。

動画の比較案としては、NDL所蔵の「慶長年間江戸図考」の復元図と「武州豊嶋郡江戸〔庄〕図」を並べるのが、権利・解像度・時期のバランスがよいです。ただし、これは「銀座の海岸線を正確に測った埋め立て前後図」ではありません。以下の年代ラベルを付けて「江戸初期の地図表現の比較」として見せるのが安全です。

- 左：慶長13年ごろ（1608年ごろ）の江戸を描くとされる図（後世の復元との見方が有力）
- 右：寛永7〜8年ごろの屋敷配置を示すとされる江戸図（刊行年は後年の可能性あり）
- 画面注記：地図ごとに縮尺・方位が異なり、海岸線の精密な比較図ではありません。現在の銀座位置は目安です。

地図上に現代の銀座の境界はありません。両図の南東側の市街・水際が現在の銀座周辺に当たる可能性は示せますが、境界線ではなく「現在の銀座付近」のピンで示してください。ピンの位置を確定するには、動画に重ねる前に現代図との位置合わせが必要です。

### PID 1286168 と 2542454 の選び分け

- **年代の説明を優先する場合：PID 1286168。** NDL解説に寛永期の内容年代があり、全図が1画像なので取り回しも簡単です。ただし刊行年と内容年を同一視せず、解説の留保も残してください。
- **銀座周辺を大きく見せる場合：PID 2542454。** 分割画像の画素数が大きく、部分拡大に向きます。ただし地図の左右を結合する必要があり、NDL書誌に原図の内容年代が記されていません。年代は「1833年写本」と資料の成立年で表示し、「寛永期の地形」と言い切らないでください。
- 2542454は1286168とは別の年代を独立に証明する資料として並べるものではありません。同系統の図の写本・版の違いとして扱います。

**推奨する後図はPID 1286168**です。年代を画面で説明しやすく、全体図を一枚で確認できます。小さな地名が読みづらい場合はPID 2542454を拡大表示用に検討できますが、写本年代と内容年代を分けて記します。

## 画面への推奨表示

比較をするなら、まず現代地図で銀座の位置を示し、次に各古図を一枚ずつ見せます。図の方位・縮尺を揃えたように見せず、地図ごとに同じ「現在の銀座付近」ピンを置き、現在図へ戻る位置案内を入れます。地図の小字はスマホでは読めないため、説明対象を絞って大きく寄ります。

ナレーション例：

> こちらは、慶長期の江戸を描いたとされる復元図です。日比谷の入江が残る姿が描かれています。次の図は、寛永期の町割を示すとされる江戸図です。地図の描き方や年代には不確かさがあり、銀座の正確な海岸線を示すものではありません。

「銀座全体が砂州だった」「両側が埋め立てられて今の銀座になった」「標高から江戸時代の海岸線が分かる」とは言わないでください。安全な短い表現は「江戸前島の南端付近に、現在の銀座が位置するとする復元があります。範囲や海岸線には諸説があります」です。
