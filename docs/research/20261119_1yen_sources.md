# 1円玉の製造コスト：出典確認（2026-11-19）

題材: 「1円玉は、作るのに1円以上かかる？」＝ **作るのに1円以上かかる、という公式な数字は存在しない**。

## 確認した一次資料

1. 独立行政法人造幣局「貨幣Q&A」 https://www.mint.go.jp/faq-list/faq_coin （2026-11-19に本文確認）
   - 問「貨幣の製造原価を教えてください。」に対し:
     > 貨幣の製造原価（コスト）については、国民の貨幣に対する信任を維持するためや、貨幣の偽造を助長するおそれがあると考えられることから、公表していません。
   - 同ページ: 「造幣局は貨幣の『製造』を行い、政府（国）が貨幣を『発行』します」「財務大臣が造幣局に対し支払う貨幣の製造代金は、貨幣の製造原価等を勘案して算定する」（根拠: 通貨の単位及び貨幣の発行等に関する法律第4条）。

2. 造幣局「現在製造している貨幣」 https://www.mint.go.jp/operations/production/operations_coin_presently-minted.html （2026-11-19に本文確認）
   - 1円貨: 材質＝アルミニウム、重量＝1g、直径＝20mm（同ページの表）。

## 使わない・留保

- 「1円玉を造るのに3円かかる」という話は、造幣局が原価を公表していないため**公式には確認できない**。断定的に言わない。
- 材料費だけで製造原価が決まるわけではない（回収した硬貨の再資源化、製造・流通の費用など）。造幣局のQ&Aは「公表しない」理由として信任維持と偽造防止を挙げている。
- 原価の推計を報じた報道・雑学記事は、一次資料ではないため台本の断定根拠に使わない。
- 造幣局の「製造原価公表なし」は2026-11-19時点の記述。方針変更の可能性があるため、動画内にも確認日を入れる。

## 構成（30〜45秒・4場面）

1. 疑問: 「1円玉は、作るのに1円以上かかる？」
2. 結論の方向: 「公式な原価は、公表されていない」
3. 根拠: 造幣局Q&Aが「公表していない」と明記。理由は信任維持と偽造防止。
4. 回収: 1円玉はアルミニウム・1g。だから「3円」と断定できない。2026年11月19日時点の情報。
