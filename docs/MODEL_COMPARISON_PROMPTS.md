# モデル比較検証：各モデルに貼る指示文（コピーして使う）

使い方
1. 3つのモデルを、**1つずつ順番に**動かす（書き出しとVOICEVOXを共有するので、同時に動かさない）。順番はくじで決める。
2. 各モデルには、下の「共通の指示文」を貼る。**変えるのは、先頭の `<SLUG>` だけ**。
   - Sonnet 5.5 → `sigsonnet`／GPT-6 Luna → `sigluna`／DeepSeek V4.1 Flash → `sigdeepseek`
3. 貼ったあと、**追加の指示・助言・やり直しの指示は出さない**。質問されたら、「指示文のとおりに判断して進めて」とだけ返す。
4. 終わったら、モデルの最終報告をそのままコピーして保存する（`docs/MODEL_COMPARISON_LOG.md` に貼る）。
5. 開始時刻と終了時刻、モデルが使ったトークン数（または料金）を、あなたが記録する。

前提：3つとも、同じ作業フォルダ（`E:\rekishikaisetu-honnoji`、同じコミット）で、ファイルの読み書きとコマンド実行ができること。VOICEVOX（127.0.0.1:50021）が動いていること。
