# 冒頭フックの型と実測(仮説メモ)

**使い方**: 新しいShortを作るたびに1行足す。AGENTS.md や手順書には転記しない。
1本あたり約200回再生ではノイズが大きいので、**同じ型が5本以上たまるまで「勝ち」と呼ばない**。

## 実測として確認済み(メモリより)
- 逸話型×約60秒は維持率が高め、制度・用語の説明型は冒頭で急落(2026-11-06 Analytics)
- スワイプ67%・冒頭4〜7秒で離脱(2026-11-11)。数字・問いを先に出す方針(2026-11-11)
- 初雪Short: 継続14.3%・平均視聴率33%(2026-11-12)
