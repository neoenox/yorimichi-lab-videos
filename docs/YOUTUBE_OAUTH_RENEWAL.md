## 本番（公開）に切り替える場合：ユーザーの判断
- 効果：更新トークンの7日失効がなくなる。
- 手順（Google Cloud コンソール → 「Google Auth Platform」→「対象」）：「アプリを公開」を押して、公開ステータスを「本番環境」にする。
- 注意：
  - `youtube.upload` などは機微なスコープ。**未審査（未確認）のまま本番にすると、同意画面に「このアプリは確認されていません」の警告が出る**。自分専用で使う分には、警告で「詳細」→「安全ではないページに移動」を選べば使える。
  - 未審査の本番アプリの利用者上限は100人。審査（OAuthアプリ確認）は、公開ページや利用目的の提出が要り、手間がかかる。自分用なら不要。
  - 本番に切り替えたら、**もう一度 `auth` が必要**（テスト中に出したトークンは引き継がれない場合がある）。
  - **審査前のAPIプロジェクトの動画は非公開に固定される**（YouTube API の仕様）。公開・予約は、これまでどおりAPIの `schedule` で動いている（予約公開は成功している）。
- 切り替えるかどうかは、セキュリティ設定の変更にあたるため、**ユーザーが行う**。私は代行しない。

- 失効する週に、予約の変更・旧版の削除が必要な作業を、できるだけ前倒しする。
