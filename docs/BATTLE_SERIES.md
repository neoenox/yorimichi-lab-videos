# 戦況解説シリーズ（「◯◯の戦い」）の作り方

2026-10-21、ユーザーの希望で始めた。**国内外を問わず、地図の上で軍勢（指揮官の肖像つき）を動かし、戦況がどう変わり、どうなったかを解説する**。1本目は長篠の戦い（`docs/themes/20261127_nagashino/`）。

## 形式
- 長さ：8〜10分（これまでの3分台より長い）。
- 型：①問い・結果の予告 → ②経緯 → ③両軍と指揮官（肖像）→ ④地形と布陣（地図）→ ⑤戦闘の経過（地図の上で軍勢が動く）→ ⑥決着 → ⑦その後 → ⑧通説と史料（諸説の比較）→ ⑨分かること・決められないこと。
- チャンネルの方針は変えない：**史料に帰属して言う。兵力・時刻・経路で諸説があるものは、幅で示す／説を並べる。通説と一次史料の差を、確かめて示す。**

## 画面の部品
- 地図：国内は国土地理院（地理院タイル）の現代の地形。当時の城・砦・陣の位置は、推定であることを画面に明記する（`oke_maps.py` の座標の取り方に倣う）。海外は Natural Earth ＋標高データ（利用条件を確認）。
- 軍勢：色分けした駒に、兵力のラベル。**指揮官の肖像（円形）を駒に添える**。動かす部品は `vp_anim.oke_march`（桶狭間で作成）を拡張する（複数の軍・複数の区間・退却・包囲・「軍が分かれる／合流する」）。
- 肖像：著作権の切れた古い絵（Wikimedia Commons など）。出典・所蔵者・利用条件を `05_images_rights.md` に記録。顔の描かれていない人物は、無理に補わない。
- 背景イラスト：ChatGPT（web）で、地図の章以外に敷く（桶狭間の方式）。

## 事実確認の関門（長篠の例）
1. 一次史料の原文：『信長公記』（巻八「三州長篠御合戦之事」。Wikisourceの翻刻で確認）、『当代記』『三河物語』『甲陽軍鑑』など。**写本で数字が違う箇所（鉄砲千挺／三千挺）は、写本名を言う。**
2. 兵力・時刻・経路の**諸説を表にする**（誰の説か、根拠は何か）。
3. 通説と史料の差：三段撃ち（『信長公記』に記述なし。江戸期の『甫庵信長記』が起源とされる）、馬防柵の意味、鉄砲の数。
4. 地名・位置：国土地理院の住所検索APIと、史跡・資料館の位置を突き合わせ、**ずれを数字で残す**。

## 制作の流れ
`08_fact_check.md` → 台本v1（章ごとに「どの軍が、どこからどこへ動くか」を、文の番号に対応させる）→ ChatGPT web査読 → 地図の切り出し・座標の確定 → 肖像の収集と権利 → `make_spec_<slug>.py`（軍の経路を正規化座標で書く）→ 音声 → ビルド → Codex確認 → アップ。
