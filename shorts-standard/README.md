# 寄り道ラボ Shorts 制作標準 v1.0

目的: 制作者やAIモデルが違っても、同じ題材から一貫した形式の30〜45秒Shortsを制作する。

## 運用
1. `brief.yaml` にテーマ、視聴者の疑問、一次資料URL、確認済み事実、留保を書く。
2. `PROMPT.md` を制作担当AIに渡し、`output.schema.json` に適合するJSONを生成させる。
3. `validate.py result.json` で形式を機械検査する。
4. 人間が資料の原文照合、ナレーションの自然さ、誤認を招く映像表現を確認する。
5. 合格したJSONのみ音声・字幕・FFmpeg工程に渡す。

## 固定ルール
- 9:16、1080x1920、30〜45秒、5〜7シーン。
- 0〜3秒に疑問・違和感を提示。最初の8秒以内に結論の方向性を示す。
- 1動画1疑問、主張は最大3つ、最後は一文で回収。無意味な登録誘導は禁止。
- 1シーン3〜9秒、ナレーションは1秒あたり約4〜5.5日本語文字を目安とする（実測音声で最終調整）。
- テロップは1画面2行以内、1行14文字以内。出典は画面下端に小さく押し込まず、説明欄にも明記。
- 事実の断定は根拠付き。未確認の数字、発言、因果関係は作らない。複数説がある場合は留保を明示。
- 史実再現・模式図・AI画像は実写資料と混同させず必要に応じ「イメージ」「模式図」と明記。
- 冒頭で結論をすべて説明し切らず、疑問→理由→根拠→結論の流れを守る。
- ナレーション・字幕・シーン時間は必ず一対一に対応。

## 合否
形式検査PASSに加え、出典の実在と内容の一致、誤解を招かないタイトル、音声の読み、スマホ可読性を人が確認して公開。
