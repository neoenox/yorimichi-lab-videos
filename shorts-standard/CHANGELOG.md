# 変更履歴

このディレクトリは上流の「寄り道ラボ Shorts 制作標準 v1.0」を取り込んだもの。
このリポジトリでの変更はここに記録する（上流と差分が出たことを明示するため）。

## v1.2（2026-11-23、オーナー判断）

**冒頭フック・テロップ・ループの構成を、視聴維持を意識した型に改めた。**

- `PROMPT.md` / `README.md`
  - 0〜3秒は疑問形で終わらせず、視聴者の前提を否定する一文（答えの半分の先出し）を置く
  - 結論の方向性は8秒以内、詳細な根拠は後で回収する（旧ルールの「結論を最後まで伏せる」を廃止）
  - テロップはナレーションの言い直しではなく、キーワードと数字だけに絞る
  - 図解と数字を同時に出さず、数字を先に置いてから根拠の図を見せる
  - 最後は冒頭の言葉につながるループ文で締め、チャンネル名「寄り道ラボ」を入れる
  - ループ文は登録誘導ではないことを明記し、旧来の「無意味な登録誘導禁止」は維持

### 理由

- 既存のショート（water_2l / tongue_taste_map / income_gap など）は冒頭が疑問形で終わり、回答を待つ姿勢を作ってしまっていた
- 伸びている雑学・検証系ショートは、冒頭で「えっ、そうなの？」を起こし、末尾を冒頭へつなぐ型を取る
- テロップとナレーションが同じ内容だと、どちらも読まれず情報密度が下がる

### 運用

- 既存の `shorts/*/result.json` は作り直さない。今回の変更は今後の制作に適用する
- `output.schema.json` と `validate.py` のストラクチャ検査は変更しない（ルールは制作指示側にのみ追加）
- ループ文であっても根拠のない断定や過度な煽りは禁止のまま

## v1.1（2026-11-04、オーナー判断）

**claims の根拠に AI アシスタントの回答を使ってよいことにした。**

- `output.schema.json`
  - `claims[].source_type` を追加（`primary` / `ai_assistant`、必須）
  - `claims[].source_url` を必須から任意へ（`source_type=primary` のときだけ必須）
- `validate.py`
  - `primary` は `source_url` が http(s) であることを検査
  - `ai_assistant` は `evidence_note`（質問と回答の要点）を必須にし、URL は不要
- `README.md` / `PROMPT.md`
  - 上記の使い分けと、`ai_assistant` 使用時は一次資料での裏取りが未実施である旨を明記

### 理由

- 速報性のある題材（ニュースの背景など）では、一次資料にたどり着く前でも構成を作る必要がある
- ブラウザ経由の ChatGPT など、調査の補助としての利用が現実的

### リスクと運用

- AI の回答は誤りうる（幻覚・古い情報・出典の取り違え）。**数字・固有名詞・因果関係は特に危険**
- `scripts/shorts_standard.py` は `ai_assistant` の claim があると **WARN を出す**（黙って通さない）
- 公開前に、可能な範囲で一次資料の URL を併記する（`primary` の claim を追加する）
- 誤りが判明したら、概要欄に訂正を残し、重大なら新IDで差し替える（`superseded` 運用）
